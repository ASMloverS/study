# Codcopy 实施路线图

- 版本：v1.1
- 日期：2026-09-24
- 里程碑：M1 → M5，每个里程碑交付「可运行、可验证」的版本

## M1 核心循环（单人本地可玩）

> 状态：✅ 已完成（2026-09-21）。验收证据：vitest 21 项全绿（碰撞/射线/移动/击杀重生/机器人）、三包 tsc 通过、vite build 成功、dev 服务器冒烟测试 200。运行方式：`npm install && npm run dev`。

目标：跑通「移动 → 射击 → 击杀 → 重生」最小闭环，内嵌服务器直连。

| # | 任务 | 产出 |
|---|---|---|
| 1 | Monorepo 脚手架（workspaces / TS / Vite / vitest） | `npm run dev` 可启动空白场景 |
| 2 | shared：AABB 碰撞、射线（slab）、常量、协议类型 | 单测通过 |
| 3 | 地图 warehouse.json（三区掩体布局初版）+ 地图渲染 | 浏览器看到掩体场景 |
| 4 | 权威移动（走/跳/蹲/冲刺 + 碰撞解算）+ 客户端预测和解 | 本地操控顺滑 |
| 5 | 射击 hitscan + 伤害 + 死亡/重生 + 1 个测试机器人（随机走 + 开火） | 能击杀 / 被击杀 |
| 6 | 基础 HUD：准星、血量、弹药 | 可读反馈 |

**验收**：`npm run dev` 进入对局；WASD/跳/蹲/冲刺可用；能击杀机器人并被击杀重生；预测无明显橡皮筋。

| # | 任务 | 产出 |

## 里程碑依赖与风险提示

```
M1（闭环） → M2（深度：AI/武器/HUD） → M3（广度：网络） → M4（打磨） → M5（手感：P0→P1→P3→P2→V）
      └── M3 的 Transport 抽象在 M1 即定型，M3 仅新增 ws 实现，风险前置消化
```

- 最大技术风险：预测/和解手感（M1 第 4 项尽早验证，不达标先调再前进）。
- 最大设计风险：AI 强度与掩体博弈（M2 第 4/5 项需反复试玩调参）。
- M5 风险：回滚窗口滥用与开火预测不一致（对策见 ARCHITECTURE §9）；后坐力 / 散布 / 衰减数值需长跑数据回归（沿用 M2 平衡方法论）。
