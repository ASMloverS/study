# M15 手感打磨设计：枪模区分 / 音效 CoD 化 / 连杀奖励修复

日期：2026-09-28
状态：已与用户确认

## 背景与根因分析

### 连杀奖励（空袭/集束炸弹"不生效"）

服务端激活链路经测试与端到端复现验证**本身是通的**（`server/test/streak.test.ts` 全过；通过 `createLocalGame` 真实传输层复现：5 发空袭 blast 事件、8 发集束 blast 事件均到达客户端）。真实问题在三个环节：

1. **落点投射坏损**（`server/src/game/world.ts` `groundTarget()`）：落点 = 视线与地面交点，平视瞄准 15m 外敌人时 pitch ≈ -0.03rad → 地面交点在 50m 外 → 被 clamp 到地图边界（地图 size=48，lim=23）。复现实测：玩家 (-20.5,-20.5) 平视投放，落点 (-20.5,-23.5)——砸在自己脚下 2.5m 处。准星上的敌人与实际落点相差 30-40m，导致"没炸到人"。
2. **无自伤豁免**（`explodeAt()` world.ts:800-813）：爆炸遍历所有存活玩家，不排除使用者。落点 clamp 到自己附近时 → 自杀（`cause:'suicide'` 不记击杀且连杀清零）→ 用户观察到"连杀奖励杀敌没有积累"。
3. **无 incoming 表现**：激活到爆炸仅 1.5s，无飞机音效/烟雾标记/小地图预警；远处爆炸粒子小、声音经距离衰减后近乎不可闻 → 体感"什么都没发生"。

击杀计入逻辑（`killPlayer`，无 cause 过滤）已验证正确，落点修复后 kills/streak 自然累积。

### 枪模区分度

- 第一人称（`client/src/render/viewmodel.ts`）：7 把枪全为程序化几何，AR 与 LMG 虽有差异（LMG 有两脚架/弹药箱/提把）但轮廓比例不够夸张。
- 第三人称（`client/src/render/actors.ts` `gunFor()`）：仅 2-4 个盒子拼装，几乎无法区分枪种。

### 音效

- 全部 Web Audio 实时合成（仓库零音频文件），每枪仅 noise burst + sine thump 两层（`client/src/audio.ts` `emit()`），参数差异小。
- 爆头（880Hz）与命中（1318Hz）均为三角波 blip，几乎听不出差别。

## A. 连杀奖励修复

### A1. CoD 式俯图放置模式

按 `5`/`6` 进入放置模式（不再立即投放）：

- **UI**：屏幕中央大型北向朝上战术地图（canvas，复用小地图的地图数据绘制：墙体/掩体/自己位置）。UAV 激活期间额外显示敌人红点（奖励联动）。
- **交互**：保持指针锁定，鼠标增量驱动虚拟光标选点；空袭显示航线箭头+5 弹落点连线（初始航向 = 玩家当前朝向），滚轮/`Q`/`E` 旋转航线；集束显示 8m 散布圆（无航线）。
- **确认/取消**：左键确认投放（发送激活）；右键/`Esc` 取消（奖励不消耗，退出放置模式）。
- **落点**：任意地图内点位（服务端 clamp 到地图边界），彻底废除 `groundTarget()` 视线投射。
- 俯图上敌人仅 UAV 激活时显示。

### A2. 协议与服务端

- `InputMsg`（`shared/src/protocol.ts`）增加可选字段 `streakTarget?: { x: number; z: number }`、`streakYaw?: number`。
- 服务端 `enqueueInput` 校验：数值有限、clamp 到地图边界、yaw 规范化。
- `activateStreak()`：tier 2/3 使用客户端落点与航线角；删除 `groundTarget()`。
- `explodeAt()` 增加 `exemptId?: number` 参数：空袭/集束调用时传使用者 id，跳过对其伤害；手雷调用不变。
- 击杀计入逻辑不动。

### A3. 全套 Incoming 反馈

- `AIRSTRIKE_DELAY_TICKS` 45 → 90（3s）。
- `streakUse` 事件（已含 target+yaw）触发所有客户端：
  - 合成喷气机呼啸音：3D 空间化（PannerNode），沿航线方向扫过的滤波噪声扫频。
  - 目标区红色烟雾标记 FX（投放确认即出现，持续至爆炸+1s）。
  - 小地图红色预警圈（3s 存续，所有玩家可见）。
- 爆炸增强：更大火球粒子、sub 低频层、更远的震动衰减曲线。

### A4. 顺手清理

- 客户端 UAV 时长硬编码 `15000`（main.ts）改用共享常量 `UAV_DURATION_TICKS`，消除死常量。

## B. 枪模区分度（夸张轮廓）

**设计规则**：每把枪在三个维度形成唯一轮廓组合——枪口长度分级 / 弹匣形制 / 枪托形制：

| 枪 | 枪口长度 | 弹匣 | 枪托 | 夸张点 |
|---|---|---|---|---|
| 手枪 | 最短 | 握把内藏 | 无 | 现状已可 |
| SMG | 短 | 长弯曲弹匣 | 金属丝折叠 | 更紧凑 |
| AR | 中 | 弧形弹匣 | 全尺寸 | 收窄机匣，纤细卡宾感 |
| SG | 中长 | 无（侧挂弹） | 全木质 | 保留木纹+双管 |
| DMR | 长 | 直匣 | 骨架 | 保留瞄具镜筒 |
| LMG | 长+粗 | 大弹鼓/弹药箱+弹链外露 | 全尺寸+提把 | 全面放大：粗护木散热槽、两脚架 |
| SR | 最长 | 内藏 | 全尺寸 | 加大枪口制退器 |

- 第一人称（`viewmodel.ts`）：重点改造 AR（收窄）与 LMG（放大+弹链+脚架），其余微调；附带每枪摇摆/晃动幅度系数（重枪更沉稳）。
- 第三人称（`actors.ts` `gunFor()`）：升级为 4-8 件套，每枪至少一个标志件（LMG 弹鼓、SR 长管+镜、SG 泵、SMG 丝托等），复用共享几何。
- **回归测试**：每枪 builder 输出的包围盒尺寸断言（如 LMG 宽高 > AR），防未来退化。

## C. 音效 CoD 化

### C1. 枪声五层合成

每发枪声 = crack（2-6kHz 尖锐噪声 30-60ms）+ body（200-900Hz 频带噪声 80-150ms）+ sub（50-80Hz 正弦砰）+ tail（共享 convolver 混响、合成 IR）+ mech（枪机机械音：栓动枪明显、自动武器轻微）。

每枪参数表拉开差距：SMG 短促高频轻尾；AR 均衡；LMG 低沉轰+重机械感+长尾；DMR 单发重拳；SG 宽域轰鸣；SR 巨响最长尾；手枪轻脆。

### C2. 命中反馈（MW 风）

- 爆头：高频 crack（3-5kHz）+ 低频 thunk（150-250Hz 阻尼）双层。
- 身体命中：柔 thud tick（~300Hz，短促低响度）。
- 击杀确认音保持现状。

### C3. 空间与母带

- 远处枪声按距离做低通滤波（越远越闷）。
- 混响 send 仅用于本地枪声。
- 主通道加 DynamicsCompressor 防多枪同响削波。
