# Codcopy 游戏设计总案

- 版本：v1.1
- 日期：2026-09-24
- 状态：已确认（含 M5 手感迭代设计：基线 MW2019 枪械手感 + BO6 全向移动）

## 1. 项目概述

| 项 | 内容 |
|---|---|
| 定位 | 浏览器端 COD 风格第一人称射击游戏 |
| 模式 | FFA 个人混战（死斗复活制） |
| 平台 | 桌面 Chrome / Edge 最新版 |
| 技术 | TypeScript + Three.js（客户端）/ Node.js + ws（服务器） |
| 对战规模 | 8 人局（真人不足时 AI 补位） |

| 画面 | Low-poly 简洁风（几何体 + 纯色材质 + 雾效） |

## 2. 玩法规则（FFA 死斗）

- **胜利条件**：率先达到 20 杀，或 10 分钟计时结束（击杀数最高者胜；同杀数比死亡数，再同则并列）。
- **重生规则**：死亡后 3 秒重生；出生点从远离最近敌人的候选点中随机选择；满血满弹复活。
- **无拾取系统**：地图不刷医疗包 / 弹药，死后满状态复活。
- **回血**：受击后 5 秒未再受伤，以 20/s 回复至满血（COD 式回血）。
- **播报**：击杀播报（killfeed）、连杀提示（3/5/8 连杀文案）。
- **结算画面**：最终排名、KDA、命中率、最长连杀。
- **已确认默认值**：3 把武器全带；20 杀 / 10 分钟。

## 3. 移动手感（COD 级）

### 3.1 操作绑定

| 操作 | 按键 | 说明 |
|---|---|---|
| 移动 | WASD | 常规八方向移动 |
| 战术冲刺 | Shift | 单档战术冲刺 7.4 m/s；FOV+10、武器高举姿态；开火立即打断并进入 sprint-out 计时 |
| 跳跃 | Space | 常规跳跃（保留水平动量）；空中朝可攀爬台阶前推自动翻越（mantle） |
| 蹲下 | Ctrl | 低姿态；身高降至 1.2m，可藏于 1.1m 矮墙后 |
| 滑铲 | 冲刺中按 Ctrl | 动量滑铲（初速继承当前速度），期间可腰射开火（散布 ×1.5）；跳跃取消滑铲并保留动量；冷却 0.6s |
| 开镜 | 右键（按住） | FOV 收缩、移速下降、散布锐减；狙击开镜显示镜片 overlay；打断冲刺 |
| 射击 | 左键 | 按武器射速逻辑（全自动 / 泵动 / 栓动半自动）；冲刺中按下立即打断冲刺，sprint-out 计时结束后开火 |
| 换弹 | R | 战术换弹 / 空仓换弹（+0.6s 上膛）；切枪打断换弹且进度丢失；空仓自动换弹 |
| 切枪 | 1 / 2 / 3 或滚轮 | 切换步枪 / 霰弹 / 狙击；Q 快速切回上一把武器；时长按武器 0.45 / 0.60 / 0.70s（收枪 40% + 举枪 60%） |

### 3.3 手感细节

- **后坐力**：垂直爬升固定（可学习压枪）+ 水平随机漂移（不可背板）；服务端权威影响弹道，客户端本地即刻表现；停火后自动恢复。基线：AR 垂直 0.35°/发 + 水平 ±0.15°/发；SG 垂直 1.2°/发；SR 垂直 2.5°/发。
- **动态散布**：腰射（大散布）vs 开镜（小散布）基础上叠加状态倍率：走 ×1.3 / 跳 ×2.0 / 空中 ×2.5 / 滑铲 ×1.5；准星随散布动态扩散。
- **武器摇摆（sway）**：移动 / 转视角时视图模型惯性摆动。
- **命中反馈**：命中标记（hitmarker）、爆头红色标记、受击者屏幕红晕 + 伤害方向指示、命中轻微屏幕微震。

## 4. 武器系统

三把武器同时携带，1 / 2 / 3 或滚轮切换（Q 切回上一把），重生满弹满备。全部 hitscan（射线 vs 掩体 AABB 求交），配曳光弹视觉。

| 武器 | 单发伤害 | 爆头倍率 | 射速 | 弹匣/备弹 | 换弹（战术/空仓） | 散布（腰射/开镜） | 切枪 | 定位 |
|---|---|---|---|---|---|---|---|---|
| 突击步枪 AR | 25 | ×2（50） | 600rpm 全自动 | 30 / 90 | 2.0s / 2.6s | 中 / 小 | 0.45s | 全能 |
| 霰弹枪 SG | 8 弹丸 × 12 | ×1.5 | 泵动 70rpm | 6 / 24 | 2.8s / 3.4s | 大 / 大（弹丸扩散 6°） | 0.60s | 近距爆发 |
| 狙击枪 SR | 100 | ×1.75（175） | 栓动半自动 40rpm（点击） | 5 / 20 | 3.0s / 3.6s | 极大 / 0 | 0.70s | 远距一击 |

- 伤害衰减：AR / SG 距离衰减（AR 15m 外线性降至 70%；SG 8m 外弹丸伤害减半）；SR 无衰减。
- 后坐力：垂直固定 + 水平随机（数值见 §3.3）；切枪两段动画（收枪 40% / 举枪 60%），举枪完成才可开火。
- 弹匣经济：备弹重生回满；空仓自动换弹维持；切枪打断换弹且进度丢失。
- 击杀所需时间（TTK）参考：AR 站桩 5 发 ≈ 0.4s；SG 贴身 1 发；SR 身体 1 发 + 补 1 发或爆头 1 发。

## 5. 掩体系统

所有掩体统一为 AABB 盒体，参与：玩家碰撞（圆柱 vs AABB）、子弹阻挡（射线 vs AABB）、视线阻挡（AI 感知 / 爆炸 LOS）。

### 5.1 固定掩体

| 类型 | 尺寸（参考） | 特性 |
|---|---|---|
| 混凝土高墙 | 3.0m 高，厚 0.4m | 全遮挡，不可破坏 |
| 矮墙 | 1.1m 高 | 站立露出上半身，蹲下完全隐蔽 |
| 集装箱 | 2.6m 高，6m × 2.4m | 大型掩体，可绕行；顶部经叠箱 + mantle 翻越可达（M5 解锁） |
| 木箱群 | 1.2m 高 | 中型掩体 |

### 5.2 可破坏掩体

| 类型 | 血量 | 破坏效果 |
|---|---|---|
| 木箱 | 150 | 碎裂消失 + 木屑粒子；从碰撞体 / 导航网格移除 |
| 油桶 | 80 | 爆炸：半径 3m、最高 60 伤害（随距离线性衰减）；伤害受掩体 LOS 阻挡；可连锁引爆（0.3s 延迟） |

### 5.3 动态掩体

| 类型 | 行为 |
|---|---|
| 自动滑门 × 2（中央区域） | 感应范围 2.2m；离开后保持 1s 关闭；开/关各 1s 平滑；开度 ≥ 70% 后不再阻挡玩家与子弹 |
| 升降平台 × 1（中央） | 周期 8s（4s 上 / 4s 下），行程 0 ~ 2m，托起站立玩家，改变高低差与视线 |

- 动态掩体位置 / 状态由服务器 tick 权威计算并随快照同步。
- 可破坏掩体状态变化以事件（event）广播 + 快照兜底。

## 6. 地图设计「工业区仓库」

- **尺寸**：48 × 48m 方形竞技场，外围 4m 边界墙。
- **对称性**：对角对称，保证公平。
- **出生点**：四角分布 8+ 个候选点。

### 6.1 三区布局（掩体墙分割）

| 区域 | 内容 | 设计意图 |
|---|---|---|
| 中央区 | 仓库主体 + 集装箱高台 + 升降平台 + 双滑门 | 争夺焦点，中近距离交战 |
| 两侧通道 | 矮墙 + 木箱群 + 油桶 | 游走侧翼，peek 与爆破博弈 |
| 两端出生区 | 出生点 + 滑门 / 走廊控制 | 控制进攻节奏，防出生即交火 |

### 6.2 数据化

- 地图定义为 `shared/maps/warehouse.json`（掩体列表、类型、尺寸、位置、出生点、兴趣点），客户端渲染与服务器碰撞同源。
- 导航网格：0.5m 精度 2D grid 烘焙可行走区域；可破坏掩体摧毁 / 动态掩体状态变化时更新对应格子。

## 7. AI 设计（服务器端，行为树 + 感知）

### 7.1 感知系统

| 通道 | 规则 |
|---|---|
| 视觉 | FOV 110°，视距 40m（距离衰减目标越小越难发现），射线遮挡判定 |
| 听觉 | 事件广播半径：枪声 25m / 脚步（非行走）8m / 爆炸 35m；记住声源位置 |
| 记忆 | 记录目标最后目击位置，时效 8s 衰减；丢失目标后前往搜索 |

### 7.2 行为树

```
Selector（优先级从高到低）
├─ 撤退：自身血量 < 30% 且被攻击 → 撤向最近掩体 → 绕后迂回
├─ 交战：有可见/记忆目标
│   ├─ 评估目标（血量/距离/当前武器适配度）
│   ├─ 劣势 → 寻找掩体 → peek 射击（出掩体短促开火 0.3~0.6s → 缩回 0.5~1s）
│   ├─ 换弹时机：弹匣 < 20% 且无掩体 → 先找掩体再换弹
│   └─ 走位：交战中侧移（strafe）、不规则节奏、偶尔跳跃
├─ 搜索：有最后目击位置 / 声源 → A* 前往 → 到达后环顾 2s
└─ 巡逻：在兴趣点（中央高台 / 侧翼 / 出生走廊）之间 A* 游走，偏好掩体附近路径
```

### 7.3 难度分级

| 难度 | 反应时间 | 命中精度（基线） | 决策频率 |
|---|---|---|---|
| 简单 | 0.6s | 30% | 5Hz |
| 普通 | 0.35s | 55% | 8Hz |
| 困难 | 0.15s | 80% | 12Hz |

- 精度随目标距离、目标移动速度、自身移动状态修正。
- 单人房间默认混合难度（简单:普通:困难 = 2:4:2）。

### 7.4 部署

- AI 在服务器端运行，与真人玩家使用同一套移动 / 射击 / 伤害接口，杜绝作弊差异。
- 房间真人不足 8 人时自动补位；可在建房时设置 AI 数量与难度。

## 8. HUD / UI

### 8.1 战斗 HUD

| 元素 | 说明 |
|---|---|
| 准星 | 动态扩散（随散布）；命中标记 hitmarker；爆头红色标记 |
| 血量 | 血条 + 数值；受击屏幕边缘红晕；伤害方向指示条 |
| 弹药 | 当前弹匣 / 备弹（30/90 格式）、换弹进度条、当前武器图标（3 把切换指示） |
| killfeed | 右上击杀播报（武器图标），保留最近 5 条 |
| 连杀提示 | 3 / 5 / 8 连杀屏幕文案 + 音效 |
| 计分板 | Tab 按住显示：玩家名（AI 标注）、击杀、死亡、连杀、ping |
| 小地图 | 俯视 canvas：掩体轮廓、自身位置与朝向；敌人开枪时暴露红点 2s |
| 死亡回放 | 死亡后切击杀者视角 3s，再切重生倒计时 |

### 8.2 菜单 / 流程

- **主菜单**：单机（AI 数量 / 难度设置）| 联机（昵称、服务器地址、房间列表简化为直连）。
- **设置**：鼠标灵敏度、音量（主 / 音效）、FOV（60~110）、画质档（低 / 中 / 高：粒子密度、阴影、特效层数）。
- **流程**：主菜单 → 对局 → 结算（排名 / KDA / 命中率 / 最长连杀）→ 再来一局 / 返回菜单。

## 9. 音效

| 类别 | 实现方式 |
|---|---|
| 枪声 | Web Audio 合成：白噪声 + 滤波包络（AR 短促 / SG 厚重 / SR 尖锐） |
| 命中反馈 | 短 tick（命中 / 爆头两档音高） |
| 爆炸 | 低频轰鸣 + 噪声衰减尾 |
| 脚步 | 合成短噪声，节奏与移动速度挂钩；冲刺最响 |
| 换弹 / 切枪 / 泵动 / 栓动 | 机械咔哒合成音 |
| UI | 菜单点击 / 连杀提示 |
| 空间化 | PannerNode 3D 定位 + 距离衰减 |
| 受击 | 低血量心跳声（< 30% 触发） |

## 10. 视觉（PBR + 程序化高精度模型）

- **渲染地基**：MeshStandardMaterial（金属度 / 粗糙度）+ ACESFilmic tone mapping + RoomEnvironment 环境光照 + 曝光调校；全场景（枪械 / 角色 / 地图）统一升级。
- **第一人称武器**：每枪 15~30 部件程序化构建（机匣、护木 + 导轨、准星 + 照门真铁瞄且 ADS 时对齐、弧形弹匣、握把、枪托、枪口装置、抛壳窗），材质分质（枪身金属 / 护木聚合物 / 霰弹枪木质）；双手 + 前臂持枪；联动切枪两段动画、战术冲刺高举姿态、换弹弹匣拆卸。
- **角色（远端敌人）**：拟人分节结构（头盔、战术背心躯干、骨盆、大小臂 + 手、大小腿）；程序化动画（走跑摆腿、屈膝蹲、滑铲前倾、枪随俯仰、倒地死亡）；FFA 玩家色以头盔色带 / 袖标区分；手中武器随快照武器字段切换三种枪型。
- **特效（COD 化）**：枪口焰（多层星型面片 + PointLight 闪烁 40ms + 烟缕，远端敌人开火同样显示）、曳光弹（高速移动发光弹道 ≈250m/s，替换瞬时直线）、抛壳（弹壳弹出 + 落地弹跳）、弹孔贴花（上限 32 个循环复用）、分材质命中（金属火花 / 混凝土灰雾 / 木屑，按掩体数据推断）、血雾（命中人体）、命中微震。
- **死亡表现**：拟人倒地动画 + 0.5s 后淡出。
- **配色**：工业区主题——混凝土灰、集装箱橙 / 蓝、木箱棕、警示黄黑条纹（滑门 / 油桶）。
- **画质档**：低 / 中 / 高——粒子密度、阴影开关与质量、特效层数（枪口点光 / 弹孔贴花等）。
