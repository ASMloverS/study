## 2. 玩法规则（FFA 死斗）

- **胜利条件**：率先达到 30 杀（默认，可配置 10~50），或 10 分钟计时结束（默认，可配置 5~15 分钟；击杀数最高者胜；同杀数比死亡数，再同则并列）。
- **重生规则**：死亡后 3 秒重生；出生点从远离最近敌人的候选点中随机选择；满血满弹复活。
- **重生保护**：出生后 2 秒无敌（所受伤害无效），自身开火 / 投掷 / 近战立即失效。
- **自杀规则**：爆炸 / 手雷自伤死亡不记击杀、记一次死亡并清空连杀。
- **无拾取系统**：地图不刷医疗包 / 弹药，死后满状态复活。
- **回血**：受击后 5 秒未再受伤，以 20/s 回复至满血（COD 式回血）。
- **播报**：击杀播报（killfeed，武器图标 + 爆头标记）、连杀提示（3/5/8 连杀文案）、中文语音播报（TTS：开局 / UAV 就绪 / 敌 UAV 警告 / 胜利）。
- **结算画面**：最终排名、KDA、命中率、最长连杀。
- **已确认默认值**：3 把武器全带；30 杀 / 10 分钟（可配置）；装备手雷 1 + 闪光 1。

### 3.3 手感细节

- **后坐力**：垂直爬升固定（可学习压枪）+ 水平随机漂移（不可背板）；服务端权威影响弹道，客户端本地即刻表现；停火后自动恢复。[M12] 基线：AR 垂直 0.30°/发 + 水平 ±0.10°/发；SG 垂直 1.0°/发；SR 垂直 2.2°/发；恢复 18°/s；视觉 kick 时长 −30%、初速 +40%（更清脆）。
- **动态散布**：腰射（大散布）vs 开镜（小散布）基础上叠加状态倍率：走 ×1.3 / 跳 ×2.0 / 空中 ×2.5 / 滑铲 ×1.5；准星随散布动态扩散。
- **武器摇摆（sway）**：移动 / 转视角时视图模型惯性摆动。
- **命中反馈 [M12]**：命中标记（hitmarker 音画双强化：两档音高 + 白/红标记更锐利）、爆头红色标记、击杀确认图标+音、受击者屏幕红晕 + 伤害方向指示（增强）、命中轻微屏幕微震。
- **屏息**：狙击开镜时视角有呼吸幅度摇摆（约 ±0.6°，随实际视角上传影响弹道）；按住 Shift 屏息将幅度衰减至近零，气息条 5s，耗尽后摇摆幅度加倍直至恢复。
- **ADS 灵敏度倍率 [M12]**：开镜时独立灵敏度倍率（默认 1.0，滑条 0.3~2.0，COD 标配相对倍率）。
- **起步/急停 [M12]**：地面加速度 `GROUND_ACCEL_K` 18→25（起步/变向/急停更跟手）。
- **辅助瞄准 [M12]**（纯客户端视角层，零服务端变更）：粘滞（准星距可视敌人角距 <4° 时视角速度 ×(1−强度)）+ 轻吸附（<1.5° 时向目标牵引 ≤2°/s，上限硬编码）；档位 关/低 0.25/中 0.5/高 0.75；键鼠默认关，手柄默认中档；LOS 每帧 raycast（≤8 次）。

## 4. 武器系统

**[M11] 双武器 loadout 制**：武器库 7 把，主/副武器各任选其一（可双长枪组合，默认 主AR + 副手枪）；主菜单与死亡重生等待界面可修改，下一命生效。`1`=主武器、`2`=副武器，滚轮 / Q 两把间切换；重生满弹满备。全部 hitscan（射线 vs 掩体 AABB 求交），配曳光弹视觉。切枪/换弹时长为 [M12] 提速后数值（×0.85 / ×0.90）。

| 冲锋枪 SMG | 18 | ×1.5（27） | 900rpm 全自动 | 32 / 128 | 1.5s / 2.1s | 中 / 小 | 0.30s | 0.20s | ×1.05 | 近距泼水 |
| 轻机枪 LMG | 30 | ×1.8（54） | 540rpm 全自动 | 75 / 150 | 3.8s / 4.4s | 大 / 中 | 0.72s | 0.38s | ×0.9（ADS ×0.85） | 压制 |
| 射手步枪 DMR | 50 | ×1.9（95） | 半自动 240rpm | 15 / 60 | 2.1s / 2.7s | 大 / 极小 | 0.47s | 0.28s | ×1.0 | 中远两发 |

- 伤害衰减：SMG 12m 外→65%；AR 15m 外→70%；手枪 15m 外→70%；LMG 20m 外→75%；SG 8m 外弹丸伤害减半；DMR 30m 外→80%；SR 无衰减。
- 后坐力：垂直固定 + 水平随机（数值见 §3.3）；切枪两段动画（收枪 40% / 举枪 60%），举枪完成才可开火。
- 弹匣经济：备弹重生回满；空仓自动换弹维持；切枪打断换弹且进度丢失。
- 击杀所需时间（TTK）参考（100 血）：AR 4 发 ≈ 0.30s；SMG 6 发 ≈ 0.33s；LMG 4 发 ≈ 0.33s；DMR 2 发 0.25s（需两发命中）；SG 贴身 1 发；SR 身体 1 发；手枪 4 发 ≈ 0.40s。
- 武器级字段：`moveMul`（移速倍率）/ `adsMul`（ADS 移速倍率）/ `adsTime`（开镜时长，M12）。

### 4.1 近战（melee）

- V 键触发：0.6s 动作锁（期间不可开火 / 切枪）；出招 0.25s 时刻做 1.2m 前向射线判定（走服务端 lag comp 回溯，与射击同管线）。
- 一击必杀（100 伤害）；被掩体阻挡则无效。近战击杀进 killfeed 显示近战图标，并计入连杀。

### 4.2 致命装备：破片手雷

- 携带 1 颗 / 命，重生补满；G 按住开始烹煮（引信计时开始，HUD 显示烹煮进度），松手以视角方向抛出（初速约 14 m/s + 上抛分量）。
- 引信总长 3.5s（含飞行时间，烹煮过度在手中爆炸）；服务端权威模拟弹道（重力 / AABB 反弹，恢复系数 0.35），快照 `nades` 列表同步 + 客户端插值。
- 爆炸：半径 3.5m、最高 100 伤害（距离线性衰减），LOS 遮挡判定；可破坏木箱 / 引爆油桶 / 连锁；自伤死亡走自杀规则。

### 4.3 战术装备：闪光弹

- 携带 1 颗 / 命，重生补满；E 键抛出（弹道同手雷），1.8s 引信起爆。
- 玩家致盲由客户端按「朝向夹角 + LOS 遮挡 + 距离」计算：正对无遮挡最近处最长 2.5s 全白渐退。
- AI 致盲为服务端权威：感知通道屏蔽 + 命中精度惩罚，持续同规则时长。

## 5. 连杀奖励（killstreak）

纯击杀连杀制（死亡清零）；连杀奖励造成的击杀同样计入下一条连杀。按键 4/5/6 直接激活（1/2/3 仍为武器）。

| 奖励 | 达成 | 效果 |
|---|---|---|
| UAV 无人侦察机 | 3 连杀 | 15 秒内小地图每 2s 刷新全体敌人红点（仅拥有者可见）；激活即时生效 |
| 精准空袭 | 5 连杀 | 以准星指向地面点为目标、沿玩家面朝方向投一线 5 点轰炸；1.5s 延迟（喷气机飞掠音）后逐点爆炸（半径 4m / 单点最高 120 伤直击必杀，按落点表面高度引爆，LOS 阻挡） |
| 集束炸弹 | 6 连杀 | 目标点 8m 半径内 8 点随机散布轰炸；1.5s 延迟后逐点爆炸（半径 3m / 单点最高 120 伤直击必杀，按落点表面高度引爆） |

- 每条连杀内每档奖励仅可获得一次；**[M14] 死亡后已获未用奖励保留**（计数器清零，MW2019 式），激活使用后该档重置、可重新赚取（若当前计数仍 ≥ 阈值，下一击杀即重新获得）；新对局全清。
- 空袭 / 集束可伤害自身（自伤不记击杀）；爆炸复用手雷 / 油桶同一条 `explodeAt` 管线。
- 获得与激活均有事件广播（`streakEarned` / `streakUse`）；HUD 常驻连杀进度与就绪档位提示。

## 6. 掩体系统

所有掩体统一为 AABB 盒体，参与：玩家碰撞（圆柱 vs AABB）、子弹阻挡（射线 vs AABB）、视线阻挡（AI 感知 / 爆炸 LOS）。

### 6.1 固定掩体

| 类型 | 尺寸（参考） | 特性 |
|---|---|---|
| 混凝土高墙 | 3.0m 高，厚 0.4m | 全遮挡，不可破坏 |
| 矮墙 | 1.1m 高 | 站立露出上半身，蹲下完全隐蔽 |
| 集装箱 | 2.6m 高，6m × 2.4m | 大型掩体，可绕行；顶部经叠箱 + mantle 翻越可达（M5 解锁） |
| 木箱群 | 1.2m 高 | 中型掩体 |

### 6.2 可破坏掩体

| 类型 | 血量 | 破坏效果 |
|---|---|---|
| 木箱 | 150 | 碎裂消失 + 木屑粒子；从碰撞体 / 导航网格移除 |
| 油桶 | 80 | 爆炸：半径 3m、最高 60 伤害（随距离线性衰减）；伤害受掩体 LOS 阻挡；可连锁引爆（0.3s 延迟） |

### 6.3 动态掩体

| 类型 | 行为 |
|---|---|
| 自动滑门 × 2（中央区域） | 感应范围 2.2m；离开后保持 1s 关闭；开/关各 1s 平滑；开度 ≥ 70% 后不再阻挡玩家与子弹 |
| 升降平台 × 1（中央） | 周期 8s（4s 上 / 4s 下），行程 0 ~ 2m，托起站立玩家，改变高低差与视线 |

- 动态掩体位置 / 状态由服务器 tick 权威计算并随快照同步。
- 可破坏掩体状态变化以事件（event）广播 + 快照兜底。

## 7. 地图设计「工业区仓库」

- **尺寸**：48 × 48m 方形竞技场，外围 4m 边界墙。
- **对称性**：对角对称，保证公平。
- **出生点**：四角分布 8+ 个候选点。
- **装饰层**：托盘堆 / 沿墙管道 / 灯柱 / 地面油污贴花与安全标线 / 集装箱顶细节——纯视觉、零碰撞与导航影响，按材质合批。

### 7.1 三区布局（掩体墙分割）

| 区域 | 内容 | 设计意图 |
|---|---|---|
| 中央区 | 仓库主体 + 集装箱高台 + 升降平台 + 双滑门 | 争夺焦点，中近距离交战 |
| 两侧通道 | 矮墙 + 木箱群 + 油桶 | 游走侧翼，peek 与爆破博弈 |
| 两端出生区 | 出生点 + 滑门 / 走廊控制 | 控制进攻节奏，防出生即交火 |

### 7.2 数据化

- 地图定义为 `shared/maps/warehouse.json`（掩体列表、类型、尺寸、位置、出生点、兴趣点），客户端渲染与服务器碰撞同源。
- 导航网格：0.5m 精度 2D grid 烘焙可行走区域；可破坏掩体摧毁 / 动态掩体状态变化时更新对应格子。

## 8. AI 设计（服务器端，行为树 + 感知）

### 8.1 感知系统

| 通道 | 规则 |
|---|---|
| 视觉 | FOV 110°，视距 40m（距离衰减目标越小越难发现），射线遮挡判定 |
| 听觉 | 事件广播半径：枪声 25m / 脚步（非行走）8m / 爆炸 35m；记住声源位置 |
| 记忆 | 记录目标最后目击位置，时效 8s 衰减；丢失目标后前往搜索 |

### 8.2 行为树

```
Selector（优先级从高到低）
├─ 撤退：自身血量 < 30% 且被攻击 → 撤向最近掩体 → 绕后迂回
├─ 交战：有可见/记忆目标
│   ├─ 评估目标（血量/距离/当前武器适配度）
│   ├─ 按武器与距离开镜射击（ADS，享受精度加成）
│   ├─ 劣势 → 寻找掩体 → peek 射击（出掩体短促开火 0.3~0.6s → 缩回 0.5~1s；低矮掩体蹲下）
│   ├─ 换弹时机：弹匣 < 20% 且无掩体 → 先找掩体再换弹
│   └─ 走位：交战中侧移（strafe）、不规则节奏、偶尔跳跃；受火力压制时高难度滑铲换位
├─ 搜索：有最后目击位置 / 声源 → A* 前往 → 到达后环顾 2s
└─ 巡逻：在兴趣点（中央高台 / 侧翼 / 出生走廊）之间 A* 游走，偏好掩体附近路径
```

### 8.3 难度分级

| 难度 | 反应时间 | 命中精度（基线） | 决策频率 |
|---|---|---|---|
| 简单 | 0.6s | 30% | 5Hz |
| 普通 | 0.35s | 55% | 8Hz |
| 困难 | 0.15s | 80% | 12Hz |

- 精度随目标距离、目标移动速度、自身移动状态修正。
- 单人房间默认混合难度（简单:普通:困难 = 2:4:2）。
- 困难 AI 狙击开镜自动屏息（瞄准误差进一步降低）。

### 8.4 部署

- AI 在服务器端运行，与真人玩家使用同一套移动 / 射击 / 伤害接口，杜绝作弊差异。
- 房间真人不足 8 人时自动补位；可在建房时设置 AI 数量与难度。
- **[M11] AI loadout 化**：每条 AI 命随机 loadout（长枪主武器 + 副手枪/第二长枪）；行为树距离选枪逻辑从 3 把扩展为 7 把距离适配表；近距离自动切副武器。
- **[M10] 联机房主制**：首个真人加入即房主（退出移交最早加入者）；房主可实时调整 AI 数量/难度（对局中立即生效，8 席位守恒真人优先）；击杀上限/时长下局生效。

## 11. 视觉（鲜艳卡通渲染 [M13]）

- **渲染地基 [M13]**：MeshToonMaterial（共享 3 阶 gradientMap 色阶，暗阶 0.43 起步保阴影区色彩）+ Khronos Neutral tone mapping（保色相保饱和、防过曝泛白）+ 曝光 1.30；全场景纯色无贴图；后处理链（SSAO 减弱 + Bloom 增强）按画质档开关。
- **抗锯齿 [M13]**：MSAA 4x 三档统一——中/高档 EffectComposer 渲染目标 samples=4（WebGL2 自动 resolve）、SSAO / Bloom 内部目标按 drawing buffer 尺寸创建；低档直渲吃 canvas MSAA；第一人称武器 pass 直绘 canvas 同样受益。修复缺陷：composer 自建离屏目标 samples=0（canvas MSAA 对离屏目标无效）导致中/高档世界几何零 AA（注：0.169 SSAOPass 已重写为 AO 混合进 readBuffer，不再重渲场景，故 MSAA 目标即全覆盖）。
- **提亮基线**：曝光 1.30 [M13]（亮度滑条 0.5~1.5 乘子实时叠加，renderer 层三档画质均有效）；半球光 0.75（下半球色提亮防暗部脏）/ 太阳 2.8；不使用 PMREM 环境（toon 直染光照）；雾 0xdff1fb、密度 0.0018。
- **天空**：高饱和渐变蓝天穹顶（zenith 0.16/0.5/0.95）+ 加大的暖色太阳盘与光晕。
- **工业波普色板 [M13]**（`render/palette.ts` 单一来源）：暖白灰地面 0xd8dee6 / 墙体 0xcdd6df / 矮墙 0xb4bfca、集装箱高饱和橙蓝 0xff7a1a / 0x1f8fff、木箱蜜糖橙 0xe09a3c、油桶警示红 0xff4030 + 柠檬黄环带、滑门与安全线柠檬黄 0xffd60a、升降平台与金属件青钢 0x54c8d8 / 0x9fb0bc。
- **场景装饰**：托盘堆、沿墙管道、灯柱、安全线、集装箱顶细节（几何保留、纯色化）；零碰撞 / 导航影响，按材质合批。
- **第一人称武器 [M13]**：几何 / 动画 / ADS 锚点零变更，材质鲜艳化——浅白枪身 0xeef2f6 + 灰阶机匣 0xb8c2cd + 橙色 accent 0xff7a1a（弹匣 / 枪口 / 握把）+ 柠檬黄准星点；独立武器场景灯光提亮（hemi 1.1 / key 2.0）。无手臂、独立场景双 pass（clearDepth，不穿墙不随开镜 FOV 透视缩放）、逐枪瞄具锚点 ADS 对齐、换弹（弹匣拆装 / 霰弹逐发）/ 泵动 / 栓动 / 切枪两段 / 开火枪机回退 / sway + 呼吸 idle 全保留。[M13.1] 开镜视线修复：SMG 红点镜改开放式反射镜（细框避开视线柱，环 + 发光点精确对齐 sightY）、DMR 镜筒两端开孔（openEnded）+ 半透射后镜片 + 筒内环点分划、手枪 sightY 0.028→0.04 与 SG 珠形准星归锚、AR/LMG 铁瞄后环加大 r 0.011→0.014（孔径 2.3°→2.9°）。
