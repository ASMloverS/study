# TSCOD 设计文档 — 2.5D 伪 3D COD 式混战 FPS

> 项目代号: TSCOD
> 日期: 2026-09-21
> 状态: 已确认定稿
> 目标: Python + pygame-ce 实现的 2.5D 第一人称 FFA 混战射击游戏，单机（AI 补位）优先，后续 UDP 联网

## 1. 项目概览

| 维度 | 决策 |
|---|---|
| 游戏类型 | 2.5D 伪 3D（DOOM 式射线投射）第一人称 FFA 混战 |
| 语言/运行时 | Python 3.14+（本机 3.14.3 实测） |
| 图形 | pygame-ce 2.5.8，内部低分辨率 + `SCALED` GPU 放大；性能兜底 C++ 扩展 |
| 网络 | UDP 自定义协议（可靠 RPC 层 + 不可靠快照/输入），msgpack 序列化 |
| 进程形态 | 客户端/服务器分离；单机模式客户端内嵌仿真 |
| 对局规模 | 4-8 人（不足自动补 AI 至 8） |
| 胜负规则 | FFA：先到 N 杀 或 时限到击杀最多（双条件，先到为准） |
| 中途加入 | 随时加入，立即重生参战 |
| AI | 战术型高级 AI（感知/听声/寻路/掩体/包抄），3 档难度混编 |
| 武器 | 6 种枪械 + 手雷，hitscan 为主 |
| 移动 | 走/自动冲刺/蹲/跳（可翻越半高掩体）/滑铲 |
| 输入 | 键鼠 + 手柄（SDL GameController），COD 式辅助瞄准 + 子弹磁性 |
| 生命恢复 | COD 式呼吸回血 |
| 美术/音效 | 全部程序生成，零素材文件 |
| 配置 | 全部数值 TOML 可配置（服务端权威） |

## 2. 技术栈与可行性结论（本机实测）

| 组件 | 版本 | 验证结论 |
|---|---|---|
| Python | 3.14.3 | 基线版本 3.14+ |
| pygame-ce | 2.5.8 | 2.5D 渲染可行；手柄 `pygame._sdl2.controller` API 完整（标准化按键/轴/热插拔） |
| msgpack | 1.2.2 | RPC/快照序列化 |
| numpy | 2.5.x | 音效合成与可选数学加速 |

**pygame 第一人称可行性**：pygame 无原生 3D（SDL2 的 2D 封装），第一人称通过 DDA 网格射线投射逐列渲染实现（Wolfenstein 3D 同原理）。性能瓶颈在 Python 循环而非 pygame（`blit`/`scale` 为 C 实现）；垂直视角用 DOOM 式 y-shearing（地平线偏移）+ 投影公式 z 项，零额外渲染成本。

**2.5D 能力边界**：不支持任意 6DOF 相机、层叠房间、斜坡；垂直瞄准以 y-shear 视觉 + 弹道 z 高度判定覆盖，满足本作竞技场混战需求。

## 3. 总体架构

### 3.1 单机内嵌仿真（M3 交付单机完整闭环）

```
tscod/sim/     权威仿真核心（世界/物理/战斗/AI）

client
  ├─ LocalSession   # 单机：进程内直接驱动 sim，bots 自动补位至 8 人
  └─ NetSession     # 联网：同一接口背后走 UDP 收发
```

- 客户端仅面向 `Session` 接口编程（提交输入、获取快照/事件），单机/联网切换即换实现
- 联网时 `tscod.server` 进程加载同一个 `sim` 包 + 30Hz tick + 快照广播——联网只是把仿真搬到另一进程，M4 不重写游戏逻辑
- 单机 bot 补位 = 房间人数不足 8 时自动填充；联网模式下真人加入顶替 bot

### 3.2 模块分层

| 层 | 内容 | 说明 |
|---|---|---|
| common | 地图格式/物理（射线、AABB、高度分层）/武器表/移动/协议编解码/rng | 无状态，客户端服务器共享 |
| sim | 世界状态机、战斗结算、AI（感知/行为树/掩体图/导航）、bots 补位 | 权威仿真，单机内嵌与服务器共用 |
| server | UDP 传输、可靠 RPC、快照广播、会话管理 | 仅联网需要 |
| client | 渲染、输入（键鼠/手柄/辅助瞄准）、预测、音频、HUD | |

## 4. 渲染系统

### 4.1 管线

| 环节 | 策略 | 预算 |
|---|---|---|
| 墙体 | DDA 网格射线投射，画家算法列条渲染（支持半高墙叠加） | 480 列 ≈ 2-5ms |
| 贴图列采样 | `transform.scale` 1px 纹理条 | ≈ 2-4ms |
| 地板/天花板 | 纯色/垂直渐变，不做 per-pixel floor casting | ~0 |
| 精灵 | billboard + z 高度偏移，≤16 个 | <1ms |
| 放大输出 | 内部 480×270 → `pygame.SCALED` GPU 放大 | ~0 |

- 内部分辨率默认 480×270（可配降 360×202），目标 60 FPS
- 垂直维度：蹲/跳/滑铲/手雷改变眼高与地平线偏移（y-shearing），俯仰为视口平移近似
- 镂空掩体：棋盘格抖动 pattern 列渲染
- 可破坏掩体：贴图三阶段（完好/裂纹/严重破损）

### 4.2 C++ 性能兜底

- 热点接口化：`raycast_columns()` 与列采样独立成模块
- 不达标时以 CPython C API 编写 `tscod/_fastray.cpp` 替换实现，不引入 pybind11 等构建复杂度
- 触发标准：M1 验收时 480×270 低于 55 FPS

## 5. 世界、地图与掩体

### 5.1 地图

- 32×32 网格，tile=1m，手工 JSON（cells + 出生点组 + 手雷点位）
- 布局：中央仓库（密集半高掩体近战区）/ 两条侧翼长廊（镂空围栏对峙区）/ 外部巷道（狙击线）/ 各区分散出生点，保证掩体密度分区差异

### 5.2 掩体类型

| 类型 | 挡移动 | 挡视线 | 挡子弹 | 附加 |
|---|---|---|---|---|
| 全高墙 | ✓ | ✓ | ✓ | 分割区域 |
| 半高掩体 | ✓（跳跃 feet 高于顶可翻越） | 蹲下挡 | ✓ | 核心掩体机制 |
| 可破坏（木箱/油桶） | ✓ | ✓ | ✓（有 HP） | 木箱 150HP；油桶 80HP，摧毁时爆炸（100 伤害/3m） |
| 镂空（围栏/集装箱缝） | ✓ | ✗ | 50% 穿透 + 散布惩罚 | 抖动渲染 |

- 碰撞三标志 `blocksMove` / `blocksSight` / `blocksBullets`，AI 感知与弹道复用
- 玩家胶囊：半径 0.35m，站高 1.8m / 蹲高 1.2m

## 6. 武器与战斗

### 6.1 武器表（默认值，weapons.toml 可配）

| 武器 | 伤害 | RPM | 弹匣 | 散布 | 机制 |
|---|---|---|---|---|---|
| 突击步枪 AR | 26 | 700 | 30 | 低 | 全距离主力 |
| 冲锋枪 SMG | 17 | 900 | 35 | 中 | 移动散布惩罚小 |
| 霰弹枪 SG | 8×9 | 75 | 6 | 高锥形 | 近距离致命 |
| 狙击枪 SNIPER | 120 | 45 | 5 | 腰射大散布 | ADS 后零散布 |
| 手枪 PISTOL | 22 | 400 | 12 | 低 | 换弹间隙副武器 |
| 轻机枪 LMG | 24 | 600 | 75 | 中 | 压制，举枪慢 |
| 手雷 GRENADE | 100/3m | — | 1/重生 | — | 抛物线 + 弹跳，2.5s 引信 |

### 6.2 ADS（按住式，全武器生效）

| 参数 | AR 示例 | 说明 |
|---|---|---|
| ads_time | 0.25s | 举枪过渡（LMG 更长，如 0.45s） |
| ads_fov | 70→50（狙击→20） | 视野收窄 |
| ads_spread_mult | ×0.3 | 散布减小 |
| ads_speed_mult | ×0.6 | 移速降低 |

- ADS 中断冲刺；冲刺→开枪 150ms 举枪延迟，与 ADS 统一为举枪状态机
- 手雷：G/RB 投掷，服务器 30Hz 弹丸仿真（z 物理 + 弹跳）

### 6.3 命中判定（服务器权威）

- hitscan 严格弹道优先命中（掩体优先：先判掩体遮挡再判人）
- **子弹磁性**：严格弹道未命中时，对 `gamepad` 标记的真人客户端二次检测，弹道到目标胶囊距离 ≤0.15m 判命中；AI 不参与；键鼠严格弹道
- 呼吸回血：受击 4s 无伤开始，25HP/s
- 死亡 3s 后重生

### 6.4 战斗反馈

hitmarker（服务器确认事件）/ 击杀播报流 / Tab 计分板 / 小地图（俯视网格+玩家点）/ 受击方向指示

| 动作 | 默认参数（movement.toml 可配） |
|---|---|
| 走/冲刺 | 3.8 / 6.2 m/s，冲刺仅前向 |
| 蹲 | 1.8 m/s，眼高 1.6→0.9（半高掩体挡视线） |
| 跳 | 垂直初速 4.5 m/s，feet 超过半高掩体顶即翻越 |

## 8. 输入系统

### 8.1 架构

```
client/input/
  kbmouse.py    # 键鼠 → InputState
  gamepad.py    # _sdl2.controller → InputState（死区/曲线/平滑）
  aimassist.py  # COD 式辅助瞄准三组件
  bind.py       # 统一 InputState: move(vec2)/look(Δ)/按钮位图/ads
```

服务器只看 InputState，不感知输入设备。

### 8.2 默认按键（input.toml 可改，无重映射 UI）

| 动作 | 键鼠 | 手柄 |
|---|---|---|
| 移动/视角 | WASD/鼠标 | 左摇杆/右摇杆 |
| 开火/ADS | 左键/右键 | RT/LT |
| 冲刺 | Shift | L3（自动冲刺默认开） |
| 跳跃/蹲·滑铲 | 空格/C | A/B |
| 换弹/切枪 | R/滚轮 | X/Y |
| 手雷/计分板 | G/Tab | RB/BACK |

### 8.3 手柄舒适性（COD 同款选项面）

- 响应曲线：standard（指数 ~1.8，默认）/ linear / dynamic（S 曲线，微操更细）
- 径向内死区 0.15 默认 + 外死区可调；摇杆 1-2 帧轻度平滑
- 灵敏度：腰射基准 + ADS 独立倍率（右摇杆 ×0.6；狙击按倍镜倍率再衰减）
- ADS：按住/切换可选；菜单手柄可导航（焦点高亮）
- 不做：震动、陀螺仪瞄准

### 8.4 COD 式辅助瞄准（仅手柄启用，键鼠禁用保证公平）

| 组件 | 实现 | 默认参数 |
|---|---|---|
| 减速区 Slowdown | 准星在目标锥内且 LOS 可见，摇杆响应按接近度缩放（"粘滞感"） | 锥 5°，最低响应 0.35 |
| 旋转牵引 Auto-Rotation | ADS 中目标在宽锥内移动，相机有限角速度漂移跟踪 | 锥 10°，≤25°/s |
| 开镜吸附 ADS Snap | 按下 ADS 瞬间目标在窄锥内，举枪过渡期内缓动吸附（非瞬跳） | 锥 3°，最多修正 6° |

- 档位：off / standard（默认，三组件全开）/ precision（减速增强、无牵引）
- 全部作用于客户端相机（俯仰+偏航），与本地预测/服务器权威命中兼容
- LOS 检测复用 common 射线代码

## 9. 网络协议（M4）

### 9.1 分层

| 通道 | 可靠性 | 用途 | 频率 |
|---|---|---|---|
| RPC | 可靠（seq/ack 位图 + RTT 自适应重传） | join/leave/聊天/配置拉取/对局控制 | 按需 |
| 输入 | 不可靠（带序号 + 最近 ack 快照） | 客户端输入上报 | 60Hz |
| 快照 | 不可靠（增量 + 1Hz 全量基线） | 世界状态广播 | 30Hz |

- RPC 格式：msgpack `{op, req_id?, payload}`，request/response + 服务器事件推送两种语义
- 会话：join 分配 token，心跳 3s 超时踢出，随时加入
- join 携带 `input_device: kbm|gamepad` 标记（磁吸判定用；休闲场景作弊风险可接受，见 §17）

### 9.2 同步模型

- 服务器 30Hz 固定步长权威仿真（sim 包）
- 客户端：本地移动预测 + 快照对账（共享移动代码）；命中不做预测，曳光/枪口焰即时表现，hitmarker 等服务器确认事件
- 其他实体 100ms 插值缓冲

### 9.3 RPC op 一览（初版）

| op | 方向 | 说明 |
|---|---|---|
| join | C→S | 请求加入，返回 token + 配置 + 地图 |
| leave | C→S | 主动退出 |
| chat | C→S / S→C | 聊天 |
| config.sync | S→C | 配置同步（客户端对齐服务器数值） |
| match.event | S→C | 击杀播报/对局开始结束/重生 |

## 10. AI 设计

### 10.1 感知

- 视锥 100° + LOS 射线（镂空掩体降低检出）
- 听声事件：每武器射击/脚步广播半径（按难度倍率缩放）
- 目标记忆：last-known-pos 随时间衰减

### 10.2 导航与掩体

- A* 网格寻路 + 路径平滑 + 局部避让
- 掩体图预计算：每块半高掩体两侧站立点，按距敌距/暴露面/朝向评分

### 10.3 行为树

巡逻 ⇄ 交战（strafe-peek 侧移探头）→ 换弹进掩体 → 血低撤退 → 包抄（绕行至目标侧后路径点）→ 手雷逼掩体；Selector/Sequence/Parallel + 冷却装饰器 + 每个体 bot 黑板

### 10.4 难度分级（ai.toml，可混编）

| 参数 | 简单 | 中等 | 困难 |
|---|---|---|---|
| 反应时间 | 400ms | 250ms | 120ms |
| 瞄准误差 | 大 | 中 | 小 |
| 掩体利用率 | 低 | 中 | 高 |
| 听觉半径倍率 | ×0.6 | ×1.0 | ×1.4 |

## 11. 程序生成资源

- 贴图：64×64 代码绘制（砖/金属板/木箱/围栏/油桶 + 破坏三阶段），武器 viewmodel 用几何条绘制
- 音效：numpy 波形合成（射击=噪声突发+低通、爆炸=低频衰减、脚步=短噪声脉冲、hitmarker 提示音），生成后缓存 PCM

## 12. UI/HUD 与游戏流程

- 菜单：单机（bot 数/难度选择）/ 创建服务器 / 加入 IP —— 手柄可导航
- HUD：血量（受击红边 + 回血提示）/ 弹药 / 击杀播报 / Tab 计分板 / 小地图 / 手雷数
- 对局状态机：running（击杀数或时限到）→ 结算面板（排名/战绩）→ 5s 后自动重开
- 击杀反馈：hitmarker + 击杀图标流

## 17. 风险与应对

| 风险 | 应对 |
|---|---|
| 纯 Python 渲染不达标 | C++ `_fastray` 扩展（接口已预留）；降内部分辨率 |
| UDP 可靠层复杂度 | RPC 仅用于低频控制流，游戏数据全走不可靠通道 + 冗余发送 |
| AI 行为树失控 | 全参数 ai.toml 化 + 集成测试长时间跑局 |
| 磁吸被伪造 input_device 滥用 | 休闲定位可接受；后续可加服务器输入启发式检测 |
| 2.5D 手感与预期偏差 | M1 尽早可玩验证，参数全开放 |
