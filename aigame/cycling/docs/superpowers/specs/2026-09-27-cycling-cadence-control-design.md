# 公路车竞速游戏迭代设计：踏频控制 / 体力强化 / 音乐嵌入

- 日期：2026-09-27
- 状态：已确认（brainstorming 产出，两轮问答）
- 基线：`docs/superpowers/specs/2026-09-27-cycling-gearing-feed-music-design.md`（上一迭代已合入 main）

## 1. 迭代目标

1. 踏频控制系统：齿比全自动跟随目标踏频，玩家以 W/S 调节目标踏频（地形默认 90/110/120）。
2. 体力强化：玩家体力池 32000 → 40000，补给恢复 18% → 25%/区。
3. 音乐落地：从 FreePD（CC0）下载 3 首轻快曲目嵌入 `public/music/`，开箱即响。

## 2. 踏频控制模型

- **齿比全自动**：每 0.5s（沿用 shiftTick）自动选择使实际踏频最接近目标踏频的 cog（复用泛化后的 `aiShift(speed, cog, target)`，含 3rpm 滞回）。手动换 12 档的交互移除。
- **目标踏频 = 地形默认 + 玩家偏移**：
  - 地形默认：坡度 `> +2%` → 90（爬坡）、`< −2%` → 120（下坡）、其余 → 110（平路）
  - W/S 或 ↑/↓ = 偏移 ±5rpm，钳位 ±30；忽略按键重复
  - 地形类别切换时偏移清零（回该地形默认）；同地形内偏移保留
- 1-4 功率档、A/D 横移、M 静音不变。
- 偏移为仿真侧状态（`RiderState.cadOffset` + 地形类别记忆），输入层只发一次性 ±5 事件（`RiderCommand.cadDelta`），保证地形重置逻辑归属 sim、确定性不变。

## 3. 效率曲线适配（加宽窗口）

```
满效 [80, 125] rpm（三个地形默认全部满效）
线性衰减 50–80 与 125–150 → 0.55
≤50 或 ≥150 钳 0.55
```

- 踏频调节的机械意义：高目标抬高下坡踩空上限（52×10 @120rpm ≈ 78 km/h）、低目标改善极低速重踩（起步/陡坡）；窗内调节主要是骑感与策略自由度。
- AI 保持固定目标 95rpm（差异化，不随地形切换）。

## 4. 体力强化

- 玩家 `maxEnergy 32000 → 40000`（AI 池不变）：纯池冲刺 40000÷250 = 160s，加双区补给共 240s（比赛约 445s）；巡航可持续 1000s。
- `feedZoneGain 0.18 → 0.25`（按距离分摊不变）：玩家每区 +10000J，AI 每区 +5500~6500J，规则对称。
- 回归红线（实现期用户决策更新）：实测 40000+25%+自动变速下无脑全程冲刺结构性占优（reckless 369.1s vs 匀速自动挡 445.7s，快 AI 集团 ~50s；撞墙惩罚阶梯 0.35/0.30/0.25 实测均无法翻转，差距源于 230s 全功率冲刺期本身）。**用户选择保留宽裕经济，试玩后再调**；测试契约改为"冲刺流依赖补给仍顺畅完赛（<500s）"。若日后要求恢复体力管理核心地位，候选结构改法：低能量功率线性滑坡 / 消耗立方曲线 / 回调经济。

## 5. HUD

- 档位行：`52×18 · 96/110rpm · 巡航`（实际/目标，两者相差 ≤3rpm 时只显示一个数）。

## 6. 音乐嵌入

- 从 FreePD（CC0，公有领域，无需署名）挑选 3 首：calm（平静）/ intense（轻快激烈）/ sprint（冲刺激昂），下载为 `public/music/{calm,intense,sprint}.mp3`。
- `SOURCES.md` 登记曲目名、作者、来源 URL 与 CC0 授权。
- 播放/淡变/降级逻辑沿用上一迭代（三档交叉淡变、缺文件静音、M 静音）。

## 7. 影响面与测试

- `drivetrain.ts`：效率曲线窗口常量、`terrainCadence(gradient)`、`aiShift(speed, cog, target)` 参数化。
- `input.ts`：W/S → 一次性 `cadDelta ±5`（command() 消费后清零）；cog 相关逻辑移除。
- `race.ts`：`RiderState` 以 `cadOffset` + 地形类别替代玩家 cog 路径；玩家自动变速用 `terrainCadence(gradient) + cadOffset` 目标；玩家池 40000。
- 测试更新：效率边界新值（eff(65)=0.775、eff(70)=0.85、eff(120)=1、eff(140)=0.73 等）、input 用例重写（cadDelta/钳位/消费语义）、heavy-cog 用例随手动齿比移除而删除、reckless/paced 用例改用新 cmd 形态、补给断言按 25% 更新。

## 8. 验收标准

1. W/S 即时调节目标踏频（HUD 实际/目标联动），地形切换默认值切换且偏移清零。
2. 齿比全程自动，爬坡/下坡/平路 HUD 齿比与地形匹配（爬坡大飞轮、下坡小飞轮）。
3. 冲刺体感明显更宽裕（40000 池 + 25%/区），无脑全程冲刺可完成且占优（用户确认的爽快向平衡，待试玩反馈）。
4. 游戏启动开箱即有三档背景音乐（FreePD CC0），M 静音、SOURCES.md 有完整登记。
5. 全部单测通过；确定性保持（同输入同结果）。
