# 公路车竞速游戏 MVP 设计文档

- 日期：2026-09-26
- 状态：已确认（brainstorming 产出）
- 版本：MVP v0.1

## 1. 游戏方向

Web 端真 3D（Three.js）公路车大组赛竞速游戏。玩家在一场 5~8 分钟的比赛中，
通过功率档位管理体力、利用跟车省力、把握进攻与冲刺时机，与 6~8 名 AI 车手对抗，
争夺名次。核心乐趣 = 体力分配的策略性 + 公路车战术（跟车/进攻/冲刺）。

## 2. 核心循环

```
进入比赛 → 倒计时出发 → 档位控制功率 + 跟车省力 → 爬坡/响应进攻 → 终点冲刺 → 结算名次
```

一局 5~8 分钟，随时可再来一局。

## 3. 功能范围

### P0（MVP 必需）

| 模块 | 内容 |
|---|---|
| 骑行物理 | 功率→速度模型：滚动阻力 + 空气阻力 + 坡度重力；纯函数实现 |
| 体力系统 | 体力条；4 档功率（轻松/巡航/发力/冲刺）；高功率消耗快；透支后功率受限 |
| 跟车 | 前方近距离有车手时风阻降低约 30%，消耗随之下降 |
| 赛道 | 1 条 spline 路径赛道（约 8km，1~2 段爬坡 + 终点直道），数据驱动高程剖面 |
| 车手控制 | 键盘：功率档位切换 + 赛道宽度内左右移动占位（不做自由转向） |
| AI 车手 | 6~8 名，行为式 AI：跟轮、响应进攻、爬坡掉队、终点冲刺；参数分型（爬坡型/冲刺型等） |
| 比赛流程 | 起跑（倒计时）→ 比赛 → 冲线 → 结算（名次/时间/均功率） |
| HUD | 速度、当前档位、体力条、坡度%、剩余距离、名次、迷你高程图 |
| 摄像机 | 追尾第三人称 |

### P1（时间允许）

- 音效（风声/链条声随速度变化）
- 摄像机视角切换
- 赛后数据回放曲线（功率/速度/体力）

### 明确不做（YAGNI）

多人联机、生涯/成长/装备系统、天气、真实地图、变速与踏频硬核模拟、
车手碰撞物理、复杂菜单（仅最简开始界面）。

## 4. 系统要点

- **物理模型**：以真实公式简化，`P = F_rolling + F_drag + F_gravity` 换算速度；
  跟车仅作用于空气阻力项。物理为纯函数，便于单元测试。
- **AI**：行为式（非学习型），基于自身体力/位置/坡度做有限状态决策；
  不同车手给不同功率与体力参数形成差异。
- **赛道**：路径 + 高程均数据定义，渲染与逻辑共用同一份数据。
- **视觉**：low-poly 风格，程序化生成路网与路侧元素，控制美术成本。

## 5. 技术架构

- 技术栈：TypeScript + Vite + Three.js + Vitest
- 架构：自研轻量 game loop；Three.js 仅负责渲染，物理/AI/比赛规则为独立纯逻辑模块
- 测试：物理模型（功率→速度、跟车收益、体力消耗）与 AI 决策做单元测试

## 6. 验收标准

1. 一场比赛完整可玩（起跑到结算，5~8 分钟）
2. AI 有对抗性：会跟车、会掉队、会终点冲刺
3. 体力管理有策略性：无节制冲刺会导致体力崩盘并掉名次
4. 浏览器稳定 60fps
5. 物理与 AI 核心模块单元测试通过
