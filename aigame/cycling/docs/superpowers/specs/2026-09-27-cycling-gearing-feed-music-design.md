# 公路车竞速游戏迭代设计：真实变速 / 补给系统 / 三档音乐

- 日期：2026-09-27
- 状态：已确认（brainstorming 产出）
- 基线：`docs/superpowers/specs/2026-09-26-cycling-racing-mvp-design.md`（MVP 已实现并合入 main）

## 1. 迭代目标

1. 真实变速：52T 牙盘 + 12 速 10-36T 飞轮，踏频驱动的软惩罚物理，档位+功率双控制。
2. 体力增强与补给：玩家体力 +33%，两段爬坡前各设补给区，通过时持续恢复体力。
3. 三档联动音乐：外部 mp3 素材（用户提供），平静/激烈/冲刺随比赛状态交叉淡变。

## 2. 真实变速系统

### 2.1 传动参数

- 牙盘 52T；飞轮 12 速 `[10, 11, 12, 13, 14, 16, 18, 21, 24, 28, 32, 36]`（T）。
- 轮周 2.096 m（700×25c）。
- `RiderState.cog: number`（0..11，索引 0 = 36T 最轻，11 = 10T 最重）。

### 2.2 踏频物理（软惩罚）

```
ratio   = 52 / cogT
cadence = speed / (ratio × 2.096) × 60          # rpm
eff     ∈ [60,115]rpm → 1.0
          40~60 与 115~140 线性 1.0 → 0.55
          ≤40 或 ≥140 → 钳 0.55（不归零，防死锁）
effectivePower = 功率档目标 × eff
```

- `effectivePower` 同时驱动物理（stepSpeed）与体力消耗（stepEnergy）。
- 速度为 0 时 cadence 为 0 → eff 0.55，起步可用（52×36 下 3 m/s 即 ~60rpm 满效）。
- 不做换档延迟/掉链（YAGNI）。

### 2.3 操作映射

| 键 | 语义 |
|---|---|
| W / ↑ | 变重一档（cog+1，clamp 0..11，忽略按键重复） |
| S / ↓ | 变轻一档（cog−1） |
| 1~4 | 功率档（轻松/巡航/发力/冲刺 = 0.6/1.0/1.5/2.5 × FTP，不变） |
| A/D 或 ←/→ | 横向占位（不变） |
| M | 音乐开关（不变） |

初始 cog = 6（52×16，平路巡航 ~96rpm 满效）。

### 2.4 AI 自动变速

确定性纯函数：每 0.5s 评估一次，选择使当前速度下踏频最接近 95rpm 的 cog；无随机数，确定性保持。AI 功率档决策逻辑不变。

### 2.5 HUD

档位显示 `52×14 · 96rpm`（替换现有"档位 巡航"行中的齿比信息，功率档名保留显示）。

### 2.6 数值自检（与现物理模型吻合）

- 巡航 300W 平路 10.95 m/s × 52×16 = 96 rpm 满效；
- 爬坡 5.4 m/s × 52×28 = 83 rpm 满效；
- 冲刺 52×10 @110rpm = 72 km/h（风阻自然压制实际极速）；
- 不降档爬坡 5.4 m/s × 52×16 = 48 rpm → eff ≈ 0.72，惩罚可感知。

## 3. 体力增强与补给

- 玩家 `maxEnergy 24000 → 32000`（AI 数值不变）。
- 补给区 2 个：`d ∈ [560, 610]` 与 `[2640, 2690]`（两段爬坡入口前约 100m，各 50m）。
- 区内恢复：`+4% × maxEnergy / s`（约 4.5s 通过 ≈ +18%/区，双区合计 ~36%），上限 maxEnergy。
- 全员适用（AI 骑过同区自动受益）；纯数据判定，确定性保持。
- 视觉：每区入口一座蓝色补给拱门（复用终点门造型、蓝色）；HUD 高程图在两区位置画青色刻度线。

## 4. 三档联动音乐

- 素材由用户提供，路径约定：`public/music/calm.mp3` / `intense.mp3` / `sprint.mp3`；建议无缝循环、单个 ≤2MB；文件缺失时该层静音、游戏不崩（后补文件即生效，无需改代码）。
- 播放：三条 AudioBuffer 循环源常驻，互斥音量交叉淡变（~0.8s）。
- 状态映射：`countdown`/`finished` → calm；`racing` 且剩余 >800m → intense；`racing` 且剩余 ≤800m → sprint。
- M 静音保持；AudioContext 于开始按钮点击时启动（自动播放策略）。

## 5. 影响面与测试策略

- sim：params（CASSETTE/CHAINRING/WHEEL_CIRC/踏频区间/补给区/玩家体力）、types（cog）、energy（eff 乘子）、race（cog 传递、补给恢复、AI 变速计时）、input（W/S 语义改为换档）。
- render：蓝色补给拱门；HUD 档位/踏频显示、高程图补给刻度。
- audio：外部文件三档交叉淡变重写（替换现有程序化垫乐）。
- 测试：踏频效率曲线边界（40/60/115/140rpm）、补给区恢复数值、AI 变速选择、齿比下巡航/爬坡满效、现有全场完赛与"无脑冲刺必输"回归（数值需重新调校后通过）。

## 6. 验收标准

1. 12 档真实齿比可换，HUD 显示齿比与踏频；错误齿比（重档爬坡）有明显功率损失。
2. AI 全程自动换档，爬坡/冲刺表现不劣于现状。
3. 两处补给区通过时体力明显回升（HUD 条 + 拱门 + 高程图刻度可感知）。
4. 三档音乐随比赛状态正确切换且交叉淡变，M 可静音；无音乐文件时游戏正常运行。
5. 全部单元测试通过；确定性测试（同输入同结果）保持。
