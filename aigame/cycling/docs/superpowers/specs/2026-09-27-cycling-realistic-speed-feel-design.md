# 公路车迭代设计：真实速度档 + 全感官速度感

- 日期：2026-09-27
- 状态：已确认（brainstorming 产出，三轮问答）
- 基线：`docs/superpowers/specs/2026-09-27-cycling-hyperspeed-stage-design.md`（极速版已合入 main，本迭代修正其速度量级）

## 1. 目标

1. 速度回归**真实职业档**：巡航 ~50km/h、冲刺 62-68、下坡 110-150km/h——要的是速度的体感而非夸张数值。
2. 速度感由**视觉+听觉**营造：风噪、相机微抖、路旁环境加密、低速速度线、HUD 动效、过弯倾斜、轮组模糊、动态 FOV。
3. 赛道参数化：默认 **15km 赛段**（单局 ~21 分钟）；150km 保留为 endurance 参数选项。

## 2. 物理回调（真实职业档，气动姿势）

| 参数 | 现值 | 新值 |
|---|---|---|
| `RACE.gearRatios` | [3.6, 6, 9, 15] | [0.6, 1, 1.5, 2.5]（180-750W @ ftp300） |
| `PHYS.CdA` | 0.002 | 0.13 |
| `PHYS.maxDriveForce` | 450 | 保留（仅起步 <2s 生效） |

- 数值预演：巡航 300W ≈ 50km/h（13.9 m/s）；发力 ≈ 58；冲刺 750W ≈ 63（跟车 ~68）；下坡 −12~15% 滑行 110-125 / 踩踏 135-150km/h。
- 齿比回归真实意义：50km/h @ 95rpm ≈ 52×14（中飞轮域）。
- 体力经济、牵引上限公式、soft-pedal、操控无限制全部不变。

## 3. 赛道参数化

- `buildTrack(stageKm = 15)`：剖面改为 u 归一化关键点，山体幅度 `min(1000, 22 × stageKm)` m（15km ≈ 330m 爬升；150km 封顶 1000m）；平面蛇形 ±0.6rad + 双 π 掉头弯沿用。
- 15km 剖面结构：起步起伏 → ~4.5-7.5km 爬坡（峰 8-10%）→ 山顶 → ~10.5-13.5km 长下坡（峰 −10~13%）→ 平路冲刺终点。
- 采样 8000 保持（15km → 1.9m 间距，平滑梯度逻辑不变）。
- 单局预估 ~21 分钟（均速 ~43km/h）。

## 4. 按赛段长度等比缩放

- AI 冲刺距离：`AI_FIELD.sprintDist × (trackLength / 150000)`（15km → 180-525m），在 createRace 处按赛段缩放（RiderType 数据保持 150km 基准值）。
- 音乐冲刺窗 / HUD 终点提示：赛段长 **4%**（15km → 600m）。
- 道具簇：位于赛段 **10%-90%，每 10% 一簇共 9 簇** ×3 箱（15km → 1.5, 3, …, 13.5km），全程理论 +90%。
- 完赛等待 30s 不变。

## 5. 速度感强化（全感官）

1. **风噪**：WebAudio 白噪声循环 buffer → 带通滤波（中心频率 300→1500Hz 随速度）→ 增益 `min(0.5, (speed/40)²)`；与音乐共用 master gain（M 键全静）；sim 确定性不受影响（纯渲染层，速度由 game 帧推送）。
2. **相机微抖**：多频正弦合成位移，幅度 `min(0.22m, (speed − 8)/70)`，speed < 8 m/s 无抖动；叠加在追尾相机位置后。
3. **环境加密**：路旁树 InstancedMesh 每 ~22m 两侧（15km ≈ 1300 棵，确定性伪随机横向 8-35m）；每 500m 里程桩（细柱）。
4. **速度线重标**：显现阈值 30 → **8 m/s**，透明度 `(speed−8)/35` 封顶 0.55，长度 `speed × 0.55` 封顶 28m。
5. **HUD 动效**：速度数字在加速时弹跳放大（CSS scale 1→1.15，150ms 过渡），减速回落。
6. **过弯倾斜**：车身 roll 随横向移动速度（帧间 lateral 差），钳 ±0.35rad，玩家与 AI 同规则。
7. **轮组模糊**：踏频 > 120rpm 时轮辐隐藏、半透明"模糊盘"显现（<120 反转）。
8. **FOV 重标**：`65° + min(20°, speed × 1.5)`（~48km/h 即达 85° 封顶）。

## 6. 不变项

操控全无限制（齿比 1T~∞、踏频 0~∞、效率恒满）、道具箱拾取机制与反馈、小地图、踏频仪表盘、条带地形+雾、玩家车高亮与模型、AI ftp ×0.9、体力几乎无压力（drain 12-75 J/s + regen）、确定性。

## 7. 影响面与测试

- `params.ts`：gearRatios/CdA 回调；道具簇常量改为按赛段推导；新增 stage 默认常量。
- `trackData.ts`：参数化剖面 + `stageKm` 参数；`trackData.test` 重标（15km±0.6km、爬升 280-380m、梯度 ±16% 且陡段存在）。
- `race.ts`：createRace 缩放 sprintDist；`race.test` cruise 命令回归 `{gear:1,...}`（cog 16 + 目标 110rpm 的 soft-pedal 上限 ~45km/h，cruise 玩家以踩踏-滑行交替 ≈45km/h 前进，与真实巡航节奏吻合），时长契约 ~21min 重标，reckless 契约复核。
- `physics.test`：巡航 (13.5, 15.5) m/s、冲刺 (17, 19)、−12% 下坡 (32, 40)、起步牵引单步值重算。
- `audio.ts`：风噪层（noise buffer + bandpass + gain，速度推送接口）。
- `camera.ts`：微抖 + FOV 新曲线；`speedLines.ts` 阈值/曲线重标。
- `trackMesh.ts`：树 InstancedMesh 重做 + 里程桩。
- `riders.ts`/`placeRider`：roll 参数 + 轮模糊盘（spokes/disc 切换接口）。
- `hud.ts`/`style.css`：速度数字弹跳。
- `game.ts`：接线（风噪速度推送、roll 计算、模糊切换、冲刺窗 4%）。

## 8. 验收标准

1. 巡航 ~50km/h、冲刺 ~65、下坡 110-150km/h；HUD 与体感一致，无 300km/h 级数值。
2. 15km 赛段 ~21 分钟完赛；爬坡明显掉速、下坡显著加速。
3. 风噪随速度增强（M 全静）；>30km/h 速度线显现；高速相机微抖；路旁树高速掠过。
4. 过弯车身倾斜；高踏频轮组模糊。
5. 全部单测通过；typecheck/build 全绿；确定性保持。
