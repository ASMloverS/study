# 公路车迭代设计：极速 150km 赛段 / 全解锁操控 / 道具箱补给

- 日期：2026-09-27
- 状态：已确认（brainstorming 产出，三轮问答）
- 基线：`docs/superpowers/specs/2026-09-27-cycling-continuous-drivetrain-sprint-design.md`（连续齿比 + 冲刺解锁已合入 main）

## 1. 目标

1. 速度层街机化：巡航 ~400、冲刺 ~530、下坡 650-720 km/h；150km 点对点赛段 15-25 分钟完赛。
2. 操控完全无限制（正确性优先，不做平衡钳制）：齿比 1T~∞、踏频目标 0~∞、任意档位任意齿比下任意踏频。
3. 补给改为马里奥赛车式路上道具箱，驶过拾取。
4. 体力几乎无压力；AI 稍弱；速度感与车清晰度视觉增强；俯视轮廓小地图；踏频仪表盘。

## 2. 物理与速度层

| 参数 | 现值 | 新值 |
|---|---|---|
| `RACE.gearRatios` | [0.6, 1, 1.5, 2.5] | [3.6, 6, 9, 15]（功率 ×6，玩家 1080/1800/2700/4500W） |
| `PHYS.CdA` | 0.32 | 0.002（全球超低风阻） |
| `PHYS.maxDriveForce`（新增） | — | 450 N（牵引力上限，防起步弹射） |

- `stepSpeed`：`fDrive = min(power / max(speed, minSpeed), maxDriveForce)`，其余公式不变。
- 平路终速预演：轻松 ~300 / 巡航 ~374 / 发力 ~483 / 冲刺 ~530 km/h；下坡 −3~−6% + 冲刺 650-720 km/h。
- 起步：静止起步（countdown 3s 不变）；0-300 km/h 约 15s。
- 完赛预估：150km ÷ 平均 ~110 m/s ≈ 22-23 分钟。
- 坡度放大：山地段 +8~15% 陡坡（巡航档 ~54 km/h 爬行，逼降档/发力）、长下坡 −3~−6%。

## 3. 操控全解锁与传动简化

- **齿比**：删除 [10,36] 钳位 → **[1, ∞) T**（下限 1 仅防除零）；`gearRatio(cog)=52/cog` 全域正确；HUD 整数齿数显示。
- **踏频目标**：删除全部钳位 → **[0, ∞)**（目标 0 = 永久滑行，规则语义保持正确）。
- **效率乘子系统整体删除**（恒满效）：删 `cadenceEfficiency` 与 `cadFullLo/cadFullHi/cadFloor/cadCeil/effMin` 参数、race 中乘子与 sprint 特殊分支（`cadHi` 公式退化为无上限钳位）；档 4 仍是最高功率档，无踏频特殊性。
- soft-pedal 保留：实际踏频 ≥ cadTarget → effort=0。
- AI 内部换挡仍用解析解且自限于 10-36T（AI 理性策略，非玩家限制）。
- 输入交互不变（Q/E ±1T 单击 + 6T/s 连发；W/S ±5 单击 + 30rpm/s 连发）。

## 4. 赛道：150km 点对点

- `trackData` 重写：确定性程序生成，点对点（不再环绕），200 控制点（~750m 间距），Catmull 采样 8000（18.75m 间距）；gradient 用相邻采样平滑（消除 18.75m 阶梯）。
- 高程剖面分段（确定性常量）：0-30km 起伏 ±2%；30-65km 长爬坡升至 +900m（含 8-15% 陡段）；65-80km 山顶缓滚；80-105km 大下坡（−3~−6%）；105-135km 起伏；135-150km 平路终点冲刺。
- 平面走向：正弦扰动的弯曲长线 + 2-3 个回头弯（转头弯半径 >200m，保证高速可控）。
- 补给与冲刺窗见 §5/§6。

## 5. 道具箱补给（替代 feed zones）

- 删除 `RACE.feedZones`/`feedZoneGain` 区段恢复逻辑、蓝色补给门、高程图补给刻度改为道具簇刻度。
- 箱阵：**每 5km 一簇 × 3 箱**（横向偏移 −1.7 / 0 / +1.7 m），簇中心位于 5,10,…,145km 共 29 簇 87 箱。
- 拾取判定（确定性）：骑手本 tick 跨越箱距离（`prevDist < 箱d ≤ dist`）且 `|lateral − 箱横向| < 0.75` → 拾取匹配箱；箱横向间距 1.7 m > 2×0.75 判定半径，一簇最多命中 1 箱（走线选择：吃/避）；每箱对每骑手仅一次（`RiderState.collected: boolean[]`）。
- 效果：每箱恢复 **10% maxEnergy**（一簇最多 1 箱，全程理论 ~+290%）。
- 渲染：半透明彩虹旋转立方体（马里奥风），被该骑手拾取后消失；AI 同样拾取（判定同规则）。
- 反馈：体力条闪白 + HUD 浮字「+10%」+ WebAudio 合成短促 blip（无外部资产）。

## 6. 体力经济（几乎无压力）

- drain 公式简化并与绝对功率解耦：`drainRate = drainRatios[gear]² × drainBase`，新增 `drainRatios = [0.6, 1, 1.5, 2.5]`（消耗档位比，drainBase 12：冲刺 75 J/s、巡航 12 J/s，与 ftp 无关）。
- 常时被动恢复：功率档 ≤1（轻松/巡航）时 `+0.15%/s × maxEnergy`（玩家 60 J/s）→ 巡航 ~11 分钟回满。
- 玩家池 40000 不变；全程无脑冲刺可完赛（8.9min 连冲 + 道具 ~+290%）。

## 7. AI 适配（稍弱）

- `AI_FIELD` 全员 ftp ×0.9（冲刺终速 ~519 vs 玩家 530 km/h，全程落后 ~30-60s）。
- `sprintDist` ×15 → 1.8-5.25 km（对齐 5km 冲刺窗）。
- 挡车/wander/解析变速（95rpm）不变；AI 同享新物理与宽松体力。

## 8. 渲染：速度感与车清晰

- **相机**：追尾 8.5→6 m、高度 3.2→2.4 m；**FOV 动态** `65° + min(23°, speed/7)`（0→160 m/s 线性至 88°）。
- **速度线**：~48 条加法混合线段粒子池，长度/透明度 ∝ 速度，speed > 30 m/s 出现，相机周围随机重生。
- **玩家车高亮**：放大 1.15×、亮红车架 + 自发光描边（backface shell）。
- **模型细化**：每轮 8 根轮辐、弯把、差异化车架管型（下管/上管/座管）、前倾骑行姿势。
- **地形**：全局地块 → 沿路条带（section 50 m × 宽 ~400 m，沿轨迹单调最近点索引 O(N) 生成，顶点高度 = 赛道高程 + 基础起伏）；远雾 1500-2800 m 与天空同色；相机 far 3000 m。

## 9. 小地图（俯视轮廓）

- 右上角 200×140 canvas：全路线 polyline 按包围盒等比缩放；路线底图与道具簇刻度预计算缓存。
- 每帧绘制：8 骑手彩色点（玩家白色大点 + 外圈）、29 道具簇蓝点、终点旗标。
- 纯函数（包围盒拟合、坐标投影）单测覆盖。

## 10. HUD

- **踏频仪表盘**：左上角半圆弧 canvas（指针式），刻度 0-240 rpm，目标踏频红区标记（超量程钉在端点），弧下数字显示精确实际/目标值。
- 档位行简化 `52×23 · 巡航`（rpm 移入仪表盘，不再重复）。
- 速度整数 km/h；剩余 `87 km`（0 小数）；最后 5km HUD 提示；高程图保留（适配 150km 新剖面）。
- 冲刺音乐 tier：剩余 ≤5 km。

## 11. 影响面与测试

- `params.ts`：gearRatios×6、CdA、maxDriveForce、drainBase 12、删效率曲线参数与 cassette 时代遗留、道具箱常量、sprintDist×15。
- `physics.ts`：maxDriveForce 接入 + 测试（终速/起步加速度/牵引上限）。
- `drivetrain.ts`：删 `cadenceEfficiency`；`aiShift` AI 内部 clamp [10,36] 保留。
- `race.ts`：钳位删除（cog ≥1、cadTarget ≥0）、效率乘子删除、道具箱拾取与 `collected` 状态、被动恢复、AI ftp×0.9。
- `trackData.ts`：150km 点对点生成 + 测试（长度 ≈150km、剖面分段高程边界、梯度范围 ±15%、回头弯数量）。
- `energy.ts`：新 drain（档位比²×base，与 ftp 解耦）+ regen + 测试。
- 渲染：`camera.ts`（距离/FOV）、`riders.ts`（模型细化/玩家高亮）、`terrain.ts`（条带）、`trackMesh.ts`（删补给门、加道具箱网格）、新增 `speedLines.ts`、`minimap.ts`、hud 仪表盘与浮字、audio 拾取 blip。
- 回归契约：全程完赛（8 骑手全完赛、avgPower 合理区间按新功率层重标定）、reckless（全程档 4）<25min 完赛、确定性（同输入同结果，`collected` 序列化友好）、全量 typecheck/build。

## 12. 验收标准

1. 巡航 ~400 km/h 体感流畅；下坡稳定突破 600 km/h；静止起步 15s 内到 300 km/h。
2. 齿比与踏频目标全程无任何钳位（含档 1-4 全档位）；效率恒满；HUD 仪表盘实时显示实际/目标踏频。
3. 150km 赛段 15-25 分钟完赛；坡段迫使降档（爬坡掉速明显）。
4. 驶过道具箱即拾取：闪白 + 浮字 + 音效；同箱不可重复拾取；AI 也会拾取。
5. 右上角小地图可见全路线与 8 骑手位置；玩家车在场景中清晰可辨（放大 + 亮红 + 描边）。
6. 全部单测通过；`npm run typecheck`、`npm run build` 全绿；确定性保持。

## 13. 风险

- 全程仿真测试 ~83000 步 ×8 骑手 ≈ 2-3s/次（可接受；断言尽量复用单次全程跑）。
- 高速定步长稳定性：最大加速度 ~7 m/s² × 1/60 = 0.12 m/s/tick，稳定。
- 条带地形与赛道贴合（穿模/抖动）：单调索引生成 + 顶点噪声受控，手动验收。
- 拾取音效：WebAudio 合成（oscillator blip），无资产依赖。
