### Key language facts driving the design (verified against docs/parser)

- Parser already checks dup declarations for `var`/`const`/`:=` (same-scope) and class names; it does NOT register params, imports, catch binds, for targets — the Binder is the name-resolution authority and re-checks everything with its own codes.
- Statement-level `var` takes ONE name (`var a, b` only inside class bodies parses as two members) — conformance cases must not use statement-level multi-name `var`.
- Func redefinition is legal (05 §1) → func names are declared (annotated) but never dup-checked.
- int `/` truncates toward zero, `%` follows dividend sign (Go/C semantics); `/` `%` by zero and int overflow both *upgrade or error at runtime* — folding must not fold div/mod-by-zero.
- `&& ||` return an operand, `!` returns bool; comparison chaining is a parse error already.
- `await` legal only in `async func` bodies and module top level; `yield` anywhere in a plain func makes it a generator (legal), but `yield` in an `async func` is illegal; `yield` at module top level is illegal.
- `break`/`continue` legal only inside the nearest enclosing loop *of the same function*; a nested func body resets loop depth. `return` at module top level is illegal.
- Loop vars (`for x in xs`, `for i := 0; ...`) are fresh bindings per iteration (04 §4) — annotate with a `fresh` flag; comprehension targets likewise (03 §2: first `for`'s iterable evaluates in the outer scope).
- Class bodies declare no lexical bindings (members are runtime attributes); method scopes chain *through* the class scope transparently. `this` is left unannotated (T020).
- Unresolved names resolve to **global** (dynamic lookup) — no "undeclared" error at bind time.
- AST payload reuse (T008): `AST_THROW/DEFER/YIELD` use `as.exprStmt.expr`; `AST_RECV/AWAIT/GO` use `as.unary` (op==0); `AST_BREAK/CONTINUE/THIS` no payload; `forStmt.target`/`selectCase.target` can be NULL (BAD_TARGET already diagnosed — binder must tolerate NULL).

## Design decisions

### 1. Bind annotations live on `AstNode` (ast.h)

New fields + enums in `src/parser/ast.h` (binder writes, dump/compiler read):

```c
typedef enum AstBindKind {
  AST_BIND_NONE = 0,
  AST_BIND_LOCAL,    // bindSlot = 所属函数帧槽位
  AST_BIND_GLOBAL,   // 模块层（含未解析名的动态全局查找）
  AST_BIND_UPVALUE,  // bindSlot = 定义函数内槽位；bindUpvalDepth = 跨函数边界数
} AstBindKind;

enum { AST_BIND_FRESH = 1 };  // bindFlags 位：每轮迭代新鲜绑定（04 §4）
```

Annotated nodes: `AST_IDENT` references; declaration nodes `AST_VAR_DECL` / `AST_FUNC_DECL` / `AST_CLASS_DECL` (their declared name). Params use the **slot-by-index convention** (param i → slot i; body locals continue at `paramCount`) — documented in `binder.h`. Catch binds / `case … as` / import aliases register in the scope chain but carry no per-node annotation (their bodies' *references* are annotated).

### 2. Error codes (MSE1xxx continuation, defined in `binder.h`)

| code | name | condition |
|------|------|-----------|
| 1017 | MSE_BIND_TOP_RETURN | `return` at module top level (04 §6) |
| 1018 | MSE_BIND_LOOP_ESCAPE | `break`/`continue` outside a loop of the current function (04 §6) |
| 1019 | MSE_BIND_AWAIT_POS | `await` in a non-async function (05 §8, 03 §8) |
| 1020 | MSE_BIND_DUP_DECL | duplicate declaration in same scope (params, imports, destructure, …) (04 §1) |
| 1021 | MSE_BIND_YIELD_MISPLACED | `yield` in an `async func` or at module top level (05 §8) |

### 3. Scope model (binder.c internals)

Scope kinds: `MODULE` / `FUNC` (params) / `BLOCK` (blocks, loop/case/catch clauses) / `CLASS` (holds no symbols — transparent boundary) / `COMPR` (comprehension & gen-expr: implicit function, upvalue boundary). Slot allocation: each FUNC/COMPR scope owns a `nextSlot` counter (starts at paramCount); every declaration in it or its child BLOCK scopes takes the next slot. Module declarations → `AST_BIND_GLOBAL`, no slot. Function body block is a child scope of the FUNC scope (so `func f(a) { a := 1 }` is legal shadowing, matching parser scopes).

Upvalue: resolving a name to a symbol of an enclosing FUNC/COMPR scope (≥1 function boundaries crossed) annotates the ident `UPVALUE(slot, depth)` and records one `BinderCapture` per intermediate function (transitive pass-through), deduped by (func, name). `binderCaptures()` exposes them for T018.

### 4. Constant folding (binder.c, post-order in expression walk)

- Domains: int (i64), float (double), bool, nil literals. String/rune/bigint operands never fold.
- Folds: `+ - * / % **` (int & float; `**` int-only, exponent ≥ 0, result ≤ 256 decimal digits else no fold), `& | ^ << >>` (int; shift count 0..63 else no fold), comparisons (same-domain only: int/int, float/float, bool/bool eq-ne, nil/nil eq-ne — mixed int/float comparisons do NOT fold), `&& || !` on bool, unary `- ~ !`.
- Div/mod by zero: no fold. `INT64_MIN / -1` → exact bigint `9223372036854775808`; `INT64_MIN % -1` → int `0`.
- Int overflow on `+ - *` and `**`: fold to `AST_BIGINT` with an **exact decimal string** (u64-wrap for add/sub, schoolbook decimal multiply for mul/pow) allocated from the AST arena; `-` unary on `INT64_MIN` likewise.
- Float ops fold via IEEE (+ − × ÷ and `fmod`) — exact/deterministic cross-platform; float `**` does not fold.
- Implementation: fold **mutates the operator node in place** into a literal node (`node->kind = AST_INT` etc.) — folded subtrees disappear from the dump.

### 5. AST dump format (`ms --dump-ast`, `src/parser/ast_dump.c`)

One node per line, 2-space indent per depth, S-expression style, **no source positions** (ignores pure position differences). Full grammar:

```
(module stmt…)                       (block stmt…)
(var x [ann] init?)                  (const x [ann] init?)
(short x [ann] init?)                (static var x…) / (static const x…)
(assign = t v)  op ∈ = += -= *= /= %= **= &= |= ^= <<= >>=
(destructure (a b *rest…) value)     ; restIndex 目标加 * 前缀
(expr e)                             (if cond then-block else?)
(for-tri init? cond? post? body)     ; 缺段以 _ 占位
(for-in (t…) iter body)              (for-cond cond body)   (for-inf body)
(while cond body)
(switch subject (case v… body)… (default body))
(switch-type subject (case T… body) (case T as x body) (default body))
(break) (continue) (return e?) (throw e) (yield e?) (defer call)
(send chan value)
(select (recv t? chan body) (send chan v body) (default body))
(import "path") / (import "path" as x)
(from "path" import a, b as c) / (from "path" import *)
(func-decl name [ann] flags? (params a b=1 *r) body|exprBody)
(func-expr flags? (params …) body|exprBody)          ; flags ∈ async generator
(class-decl Name [ann] (bases B…) member…) / (trait-decl …)
(try block (catch (T…)? name? block)… (finally block)?)
(ident x [ann]) (this) (nil) (bool true) (int 7) (float 3.75)
(bigint "9223372036854775808") (rune U+0061)
(string (lit "a") (interp e)…) / (string raw "text")
(tuple e…) (list e…) (set e…) (map (k v)…)
(binary + lhs rhs)  op ∈ + - * / % ** & | ^ << >> == != < <= > >= is in
(and a b) (or a b) (not e) (neg e) (inv e)
(ternary c a b) (call f a (spread e)…)
(index o i) (member o.name) (slice o start? end? step?)   ; 缺端 _ 占位
(comp-list value (for (t…) iter) (if c)…) (comp-map k v …) (comp-set …)
(gen-expr value (for…) (if c)…)
(recv e) (await e) (go e)
```

- `[ann]`: `[local:n]` / `[global]` / `[upvalue:depth.slot]`, plus ` fresh` suffix on per-iteration bindings. Absent annotation ⇒ no bracket.
- Strings/bigints: `"…"` with escapes `\\ \" \n \t \r` and `\xNN` for other control bytes; non-ASCII UTF-8 passes through raw.
- Floats: `%.17g`, then append `.0` if the result contains no `. e E` and is not `inf`/`nan` (keeps `1.0` distinguishable from int `1`).
- Dump order is a fixed depth-first walk → byte-identical across runs (DoD "two-run diff empty").

Overwrite the placeholder. Full file at this stage:

```c
// Binder 主体（T009）：作用域栈、名称解析与标注、位置合法性、常量折叠（见 docs/tasks/T009）
#include "binder/binder.h"

#include <stdlib.h>
#include <string.h>

#define MS_BIND_MAX_FUNCS 64  // 解析路径上最多记录的函数边界数（嵌套超深时不再记录捕获）

typedef enum ScopeKind {
  SCOPE_MODULE,  // 模块层：声明一律 global
  SCOPE_FUNC,    // 函数参数域：函数边界（槽位分配器所在）
  SCOPE_BLOCK,   // 块/循环/子句域：声明借用所属函数的槽位分配器
  SCOPE_CLASS,   // 类体：不登记词法绑定，仅作遍历边界（成员为运行时属性）
  SCOPE_COMPR,   // 推导式/生成器表达式：隐式函数边界
} ScopeKind;

typedef struct Sym {
  const char* name;  // 借用源文本
  int32_t len;
  int32_t slot;  // 所属函数帧槽位；模块层 -1
  bool fresh;    // 每轮迭代新鲜绑定（04 §4）
} Sym;

typedef struct Scope {
  ScopeKind kind;
  struct Scope* parent;
  Sym* syms;
  int32_t count, cap;
  int32_t nextSlot;     // FUNC/COMPR：槽位分配器（初值 = 参数数）
  struct Scope* owner;  // 最近函数边界 scope；MODULE = 自身
  AstNode* funcNode;    // FUNC/COMPR：对应 AST 节点（捕获记录定位）
  bool isAsync;         // FUNC：async（模块顶层视作 await 合法语境）
  int32_t loopDepth;    // 本作用域起算的循环嵌套（函数边界清零；子作用域继承）
} Scope;

struct Binder {
  AstArena* arena;
  const char* file;
  MsDiagSink* diags;
  Scope* top;
  BinderCapture* captures;
  int32_t captureCount, captureCap;
};

static void bindErr(Binder* b, const AstNode* n, int32_t len, uint32_t code, const char* msg) {
  if (b->diags == NULL) {
    return;
  }
  MsDiagnostic diag = {MS_DIAG_ERROR, code, b->file, n->line, n->col, len, msg};
  msDiagAdd(b->diags, &diag);
}

static Scope* pushScope(Binder* b, ScopeKind kind) {
  Scope* s = malloc(sizeof(Scope));
  MS_ASSERT(s != NULL);
  s->kind = kind;
  s->parent = b->top;
  s->syms = NULL;
  s->count = 0;
  s->cap = 0;
  s->funcNode = NULL;
  s->isAsync = false;
  s->loopDepth = b->top != NULL ? b->top->loopDepth : 0;
  if (kind == SCOPE_FUNC || kind == SCOPE_COMPR) {
    s->owner = s;
    s->nextSlot = 0;
    s->loopDepth = 0;  // 函数边界：循环深度重新起算
  } else {
    s->owner = b->top->owner;  // BLOCK/CLASS 借用外层函数分配器
  }
  b->top = s;
  return s;
}

static void popScope(Binder* b) {
  Scope* s = b->top;
  b->top = s->parent;
  free(s->syms);
  free(s);
}

// 同作用域查重并登记；重复发 MSE_BIND_DUP_DECL 并返回 NULL（不登记）
static Sym* declare(Binder* b, const char* name, int32_t len, bool fresh, const AstNode* at) {
  Scope* s = b->top;
  for (int32_t i = 0; i < s->count; i++) {
    if (s->syms[i].len == len && memcmp(s->syms[i].name, name, (size_t)len) == 0) {
      bindErr(b, at, len, MSE_BIND_DUP_DECL, "duplicate declaration in the same scope");
      return NULL;
    }
  }
  Sym sym = {name, len, -1, fresh};
  if (s->owner->kind == SCOPE_FUNC || s->owner->kind == SCOPE_COMPR) {
    sym.slot = s->owner->nextSlot++;  // 函数/推导式帧内分配槽位；模块层（含其块/循环域）→ global 无槽
  }
  MS_ARRAY_PUSH(s->syms, s->count, s->cap, sym);
  return &s->syms[s->count - 1];
}

typedef struct Resolved {
  Sym* sym;
  Scope* def;    // 定义所在 scope
  int32_t hops;  // 引用处与定义函数间的函数边界数（0 = 当前函数内）
  bool found;
} Resolved;

// 自内向外解析；途经函数边界入链（供捕获记录）
static Resolved resolveName(Binder* b, const char* name, int32_t len) {
  Resolved r = {NULL, NULL, 0, false};
  Scope* chain[MS_BIND_MAX_FUNCS];
  int32_t chainLen = 0;
  for (Scope* s = b->top; s != NULL; s = s->parent) {
    if (s->kind == SCOPE_FUNC || s->kind == SCOPE_COMPR) {
      if (chainLen < MS_BIND_MAX_FUNCS) {
        chain[chainLen++] = s;
      }
    }
    for (int32_t i = 0; i < s->count; i++) {
      if (s->syms[i].len == len && memcmp(s->syms[i].name, name, (size_t)len) == 0) {
        r.sym = &s->syms[i];
        r.def = s;
        r.found = true;
        r.hops = chainLen - 1;  // chain[chainLen-1] 即定义所在函数边界
        return r;
      }
    }
  }
  return r;
}

// 声明类节点标注（VAR_DECL/FUNC_DECL/CLASS_DECL 的名字；须在 declare 成功后调用）
static void annotateDeclNode(AstNode* n, const Scope* scope, const Sym* sym, bool fresh) {
  if (scope->owner->kind == SCOPE_FUNC || scope->owner->kind == SCOPE_COMPR) {
    n->bindKind = AST_BIND_LOCAL;
    n->bindSlot = sym->slot;
  } else {
    n->bindKind = AST_BIND_GLOBAL;  // 模块层（含顶层块/循环域内声明）
  }
  if (fresh) {
    n->bindFlags |= AST_BIND_FRESH;
  }
}

static void recordCapture(Binder* b, const Resolved* r) {
  // 自内向外途经的每个函数边界（不含定义函数）都记录一次捕获（透传链，T018 消费）
  int32_t index = 0;
  for (Scope* s = b->top; s != NULL; s = s->parent) {
    if (s->kind != SCOPE_FUNC && s->kind != SCOPE_COMPR) {
      continue;
    }
    if (index >= r->hops) {
      break;
    }
    int32_t depth = r->hops - index;
    bool dup = false;
    for (int32_t i = 0; i < b->captureCount; i++) {
      const BinderCapture* c = &b->captures[i];
      if (c->func == s->funcNode && c->depth == depth && c->nameLen == r->sym->len &&
          memcmp(c->name, r->sym->name, (size_t)r->sym->len) == 0) {
        dup = true;
        break;
      }
    }
    if (!dup) {
      BinderCapture cap = {s->funcNode, r->sym->name, r->sym->len, r->sym->slot, depth};
      MS_ARRAY_PUSH(b->captures, b->captureCount, b->captureCap, cap);
    }
    index++;
  }
}

// 标识符引用解析与标注（模块层/未解析 → global；跨函数边界 → upvalue）
static void bindIdent(Binder* b, AstNode* n) {
  Resolved r = resolveName(b, n->as.ident.name, n->as.ident.nameLen);
  if (!r.found || r.def->owner->kind == SCOPE_MODULE) {
    n->bindKind = AST_BIND_GLOBAL;  // 未解析或定义于模块层（含顶层块）→ 动态全局
    return;
  }
  if (r.hops == 0) {
    n->bindKind = AST_BIND_LOCAL;
    n->bindSlot = r.sym->slot;
    return;
  }
  n->bindKind = AST_BIND_UPVALUE;
  n->bindSlot = r.sym->slot;
  n->bindUpvalDepth = r.hops;
  recordCapture(b, &r);
}

void binderInit(Binder* b, AstArena* arena, const char* file, MsDiagSink* diags) {

  b->file = file;
  b->diags = diags;

  b->captures = NULL;
  b->captureCount = 0;
  b->captureCap = 0;
}

void binderDestroy(Binder* b) {
  free(b->captures);
  b->captures = NULL;
  b->captureCount = 0;
  b->captureCap = 0;
}

const BinderCapture* binderCaptures(const Binder* b, int32_t* outCount) {
  *outCount = b->captureCount;
  return b->captures;
}
```

```c
static void bindBlock(Binder* b, AstNode* n) {
  pushScope(b, SCOPE_BLOCK);
  for (int32_t i = 0; i < n->as.list.count; i++) {
    bindStmt(b, n->as.list.items[i]);
  }
  popScope(b);
}

static void bindStmt(Binder* b, AstNode* n) {
  if (n == NULL) {
    return;
  }
  switch (n->kind) {
    case AST_MODULE: {  // 顶层语句序列（module 节点复用 list 载荷）
      Scope* mod = pushScope(b, SCOPE_MODULE);
      mod->owner = mod;
      for (int32_t i = 0; i < n->as.list.count; i++) {
        bindStmt(b, n->as.list.items[i]);
      }
      popScope(b);
      break;
    }
    case AST_BLOCK:
      bindBlock(b, n);
      break;
    case AST_VAR_DECL:
      bindVarDecl(b, n, false);  // 循环头的 fresh 变体由 Task 2 的循环处理显式传入
      break;
    case AST_EXPR_STMT:
      bindExpr(b, n->as.exprStmt.expr);
      break;
    default:
      break;  // Task 2 起逐类补全
  }
}

static void bindExpr(Binder* b, AstNode* n) {
  if (n == NULL) {
    return;
  }
  switch (n->kind) {
    case AST_IDENT:
      bindIdent(b, n);
      break;
    default:
      break;  // Task 2 起逐类补全
  }
}

bool binderBind(Binder* b, AstNode* module) {
  if (module == NULL || module->kind != AST_MODULE) {
    return true;
  }
  bindStmt(b, module);
  return b->diags == NULL || b->diags->count == 0;
}
```

```c
// 同作用域查重并登记；非 soft 重复发 MSE_BIND_DUP_DECL 并返回 NULL（不登记）
// 命中 soft 符号（函数名，05 §1 覆盖合法）不报错：同槽复用
static Sym* declareChecked(Binder* b, const char* name, int32_t len, bool fresh, const AstNode* at,
                           bool soft) {
  Scope* s = b->top;
  for (int32_t i = 0; i < s->count; i++) {
    Sym* hit = &s->syms[i];
    if (hit->len == len && memcmp(hit->name, name, (size_t)len) == 0) {
      if (!soft && !hit->soft) {
        bindErr(b, at, len, MSE_BIND_DUP_DECL, "duplicate declaration in the same scope");
        return NULL;
      }
      hit->fresh = hit->fresh || fresh;  // 覆盖/复用：不新增条目，槽位不变
      return hit;
    }
  }
  Sym sym = {name, len, -1, fresh, soft};
  if (s->owner->kind == SCOPE_FUNC || s->owner->kind == SCOPE_COMPR) {
    sym.slot = s->owner->nextSlot++;  // 函数/推导式帧内分配槽位；模块层（含其块/循环域）→ global 无槽
  }
  MS_ARRAY_PUSH(s->syms, s->count, s->cap, sym);
  return &s->syms[s->count - 1];
}

static Sym* declareStrict(Binder* b, const char* name, int32_t len, bool fresh, const AstNode* at) {
  return declareChecked(b, name, len, fresh, at, false);
}

static Sym* declareSoft(Binder* b, const char* name, int32_t len, const AstNode* at) {
  return declareChecked(b, name, len, false, at, true);
```

```c
  if (target == NULL) {
    return;

    }

// 函数声明/表达式公共绑定：默认值在外层域解析，参数按序占槽（i → slot i）
static void bindFuncCommon(Binder* b, AstNode* n, ms_u8 flags, AstParam* params, int32_t paramCount,
                           AstNode* body, AstNode* exprBody) {
  for (int32_t i = 0; i < paramCount; i++) {
    if (params[i].defaultExpr != NULL) {
      bindExpr(b, params[i].defaultExpr);  // 默认值求值于定义处作用域（05 §1）
    }
  }
  Scope* fn = pushScope(b, SCOPE_FUNC);
  fn->funcNode = n;
  fn->isAsync = (flags & AST_FUNC_ASYNC) != 0;
  for (int32_t i = 0; i < paramCount; i++) {
    declareStrict(b, params[i].name, params[i].nameLen, false, n);
  }
  if (body != NULL) {
    bindBlock(b, body);  // 体块为参数域子作用域（func f(a){a:=1} 合法遮蔽）
  } else if (exprBody != NULL) {
    bindExpr(b, exprBody);
  }
  popScope(b);
```

```c
static void bindStmt(Binder* b, AstNode* n) {
  if (n == NULL) {
    return;
  }
  switch (n->kind) {
    case AST_MODULE: {
      Scope* mod = pushScope(b, SCOPE_MODULE);
      mod->owner = mod;
      for (int32_t i = 0; i < n->as.list.count; i++) {
        bindStmt(b, n->as.list.items[i]);
      }
      popScope(b);
      break;
    }
    case AST_BLOCK:
      bindBlock(b, n);
      break;
    case AST_VAR_DECL:
      bindVarDecl(b, n, false);
      break;
    case AST_ASSIGN:
      bindExpr(b, n->as.assign.target);
      bindExpr(b, n->as.assign.value);
      break;
    case AST_DESTRUCTURE: {  // *rest 形态：全部目标在当前作用域登记（任务书 §2）
      bindExpr(b, n->as.destructure.value);
      for (int32_t i = 0; i < n->as.destructure.count; i++) {
        AstNode* t = n->as.destructure.targets[i];
        if (t == NULL) {
          continue;
        }
        Sym* sym = declareStrict(b, t->as.ident.name, t->as.ident.nameLen, false, t);
        if (sym != NULL) {
          annotateDeclNode(t, b->top, sym, false);
        }
      }
      break;
    }
    case AST_EXPR_STMT:
      bindExpr(b, n->as.exprStmt.expr);
      break;
    case AST_IF:
      bindExpr(b, n->as.ifStmt.cond);
      bindBlock(b, n->as.ifStmt.thenBlock);
      if (n->as.ifStmt.elseNode != NULL) {
        if (n->as.ifStmt.elseNode->kind == AST_BLOCK) {
          bindBlock(b, n->as.ifStmt.elseNode);
        } else {
          bindStmt(b, n->as.ifStmt.elseNode);  // else if 链
        }
      }
      break;
    case AST_FOR: {
      pushScope(b, SCOPE_BLOCK);  // 循环域：头部声明 + 体（04 §4 每轮新鲜）
      b->top->loopDepth++;
      if (n->as.forStmt.form == AST_FOR_TRI) {
        if (n->as.forStmt.init != NULL) {
          if (n->as.forStmt.init->kind == AST_VAR_DECL) {
            bindVarDecl(b, n->as.forStmt.init, true);
          } else {
            bindStmt(b, n->as.forStmt.init);
          }
        }
        bindExpr(b, n->as.forStmt.cond);
        bindExpr(b, n->as.forStmt.post);
      } else if (n->as.forStmt.form == AST_FOR_IN) {
        bindExpr(b, n->as.forStmt.iter);  // 迭代源先于目标登记（03 §2 外层作用域求值）
        declareIterTargets(b, n->as.forStmt.target);
      } else {
        bindExpr(b, n->as.forStmt.cond);
      }
      bindBlock(b, n->as.forStmt.body);
      popScope(b);
      break;
    }
    case AST_WHILE: {
      pushScope(b, SCOPE_BLOCK);
      b->top->loopDepth++;
      bindExpr(b, n->as.whileStmt.cond);
      bindBlock(b, n->as.whileStmt.body);
      popScope(b);
      break;
    }
    case AST_SWITCH: {
      bindExpr(b, n->as.switchStmt.subject);
      for (int32_t i = 0; i < n->as.switchStmt.count; i++) {
        AstNode* c = n->as.switchStmt.cases[i];
        pushScope(b, SCOPE_BLOCK);  // case 体子作用域（as 绑定宿主）
        for (int32_t v = 0; v < c->as.switchCase.valueCount; v++) {
          bindExpr(b, c->as.switchCase.values[v]);
        }
        if (c->as.switchCase.bindName != NULL) {
          declareStrict(b, c->as.switchCase.bindName, c->as.switchCase.bindLen, false, c);
        }
        if (c->as.switchCase.body->kind == AST_BLOCK) {
          bindBlock(b, c->as.switchCase.body);
        } else {
          bindStmt(b, c->as.switchCase.body);
        }
        popScope(b);
      }
      break;
    }
    case AST_RETURN:
    case AST_THROW:
    case AST_YIELD:
      bindExpr(b, n->as.exprStmt.expr);  // 载荷复用（T008）；位置检查 Task 4
      break;
    case AST_BREAK:
    case AST_CONTINUE:
      break;  // 位置检查 Task 4
    case AST_DEFER:
      bindExpr(b, n->as.exprStmt.expr);
      break;
    case AST_SEND:
      bindExpr(b, n->as.sendStmt.chan);
      bindExpr(b, n->as.sendStmt.value);
      break;
    case AST_SELECT: {
      for (int32_t i = 0; i < n->as.selectStmt.count; i++) {
        AstNode* c = n->as.selectStmt.cases[i];
        pushScope(b, SCOPE_BLOCK);  // 分支体子作用域
        if (c->as.selectCase.form == AST_SEL_RECV) {
          bindExpr(b, c->as.selectCase.target);  // 可 NULL（BAD_TARGET 已诊断）
          bindExpr(b, c->as.selectCase.chan);    // RECV：AST_RECV 源
        } else if (c->as.selectCase.form == AST_SEL_SEND) {
          bindExpr(b, c->as.selectCase.chan);
          bindExpr(b, c->as.selectCase.value);
        }
        if (c->as.selectCase.body->kind == AST_BLOCK) {
          bindBlock(b, c->as.selectCase.body);
        } else {
          bindStmt(b, c->as.selectCase.body);
        }
        popScope(b);
      }
      break;
    }
    case AST_IMPORT: {
      if (n->as.importStmt.alias != NULL) {
        declareStrict(b, n->as.importStmt.alias, n->as.importStmt.aliasLen, false, n);
      } else if (!n->as.importStmt.star && n->as.importStmt.names != NULL) {
        for (int32_t i = 0; i < n->as.importStmt.nameCount; i++) {
          const AstImportName* nm = &n->as.importStmt.names[i];
          const char* name = nm->asName != NULL ? nm->asName : nm->name;
          int32_t len = nm->asName != NULL ? nm->asLen : nm->nameLen;
          declareStrict(b, name, len, false, n);
        }
      }
      break;
    }
    case AST_FUNC_DECL: {
      Sym* sym = declareSoft(b, n->as.funcDecl.name, n->as.funcDecl.nameLen, n);
      if (sym != NULL) {
        annotateDeclNode(n, b->top, sym, false);
      }
      bindFuncCommon(b, n, n->as.funcDecl.flags, n->as.funcDecl.params, n->as.funcDecl.paramCount,
                     n->as.funcDecl.body, n->as.funcDecl.exprBody);
      break;
    }
    case AST_CLASS_DECL: {
      Sym* sym = declareStrict(b, n->as.classDecl.name, n->as.classDecl.nameLen, false, n);
      if (sym != NULL) {
        annotateDeclNode(n, b->top, sym, false);
      }
      for (int32_t i = 0; i < n->as.classDecl.baseCount; i++) {
        bindExpr(b, n->as.classDecl.bases[i]);  // 基类在外层作用域解析
      }
      pushScope(b, SCOPE_CLASS);  // 透明边界：成员名不进入词法作用域（06 §1）
      for (int32_t i = 0; i < n->as.classDecl.memberCount; i++) {
        AstNode* m = n->as.classDecl.members[i];
        if (m->kind == AST_VAR_DECL) {
          bindExpr(b, m->as.varDecl.init);  // 字段初始化：仅解析初值，不登记成员名
        } else {
          bindFuncCommon(b, m, m->as.funcDecl.flags, m->as.funcDecl.params,
                         m->as.funcDecl.paramCount, m->as.funcDecl.body, m->as.funcDecl.exprBody);
        }
      }
      popScope(b);
      break;
    }
    case AST_TRY: {
      bindBlock(b, n->as.tryStmt.tryBlock);
      for (int32_t i = 0; i < n->as.tryStmt.catchCount; i++) {
        AstCatchClause* c = &n->as.tryStmt.catches[i];
        pushScope(b, SCOPE_BLOCK);  // catch 子句作用域（bindName 宿主）
        for (int32_t t = 0; t < c->typeCount; t++) {
          bindExpr(b, c->types[t]);
        }
        if (c->bindName != NULL) {
          declareStrict(b, c->bindName, c->bindLen, false, c->block);
        }
        bindBlock(b, c->block);
        popScope(b);
      }
      if (n->as.tryStmt.finallyBlock != NULL) {
        bindBlock(b, n->as.tryStmt.finallyBlock);
      }
      break;
    }
    default:
      break;
  }
}
```

```c
// 推导式/生成器表达式（03 §2）：隐式函数作用域；逐 for 子句嵌套域，目标 fresh
static void bindCompr(Binder* b, AstNode* n) {
  Scope* fn = pushScope(b, SCOPE_COMPR);
  fn->funcNode = n;
  for (int32_t i = 0; i < n->as.compr.forCount; i++) {
    bindExpr(b, n->as.compr.fors[i].iter);  // 第 i 个迭代源在第 i 层子句域求值
    pushScope(b, SCOPE_BLOCK);
    declareIterTargets(b, n->as.compr.fors[i].target);
  }
  for (int32_t i = 0; i < n->as.compr.condCount; i++) {
    bindExpr(b, n->as.compr.conds[i]);
  }
  bindExpr(b, n->as.compr.key);
  bindExpr(b, n->as.compr.value);
  for (int32_t i = 0; i < n->as.compr.forCount; i++) {
    popScope(b);
  }
  popScope(b);
}

static void bindExpr(Binder* b, AstNode* n) {
  if (n == NULL) {
    return;
  }
  switch (n->kind) {
    case AST_IDENT:
      bindIdent(b, n);
      break;
    case AST_STRING:
      for (int32_t i = 0; i < n->as.strLit.count; i++) {
        if (n->as.strLit.segs[i].expr != NULL) {
          bindExpr(b, n->as.strLit.segs[i].expr);  // 插值段
        }
      }
      break;
    case AST_TUPLE:
    case AST_LIST:
    case AST_SET:
      for (int32_t i = 0; i < n->as.list.count; i++) {
        bindExpr(b, n->as.list.items[i]);
      }
      break;
    case AST_MAP:
      for (int32_t i = 0; i < n->as.mapLit.count; i++) {
        bindExpr(b, n->as.mapLit.keys[i]);
        bindExpr(b, n->as.mapLit.values[i]);
      }
      break;
    case AST_BINARY:
      bindExpr(b, n->as.binary.lhs);
      bindExpr(b, n->as.binary.rhs);
      break;  // 常量折叠 Task 5 接入
    case AST_LOGIC:
      bindExpr(b, n->as.binary.lhs);
      bindExpr(b, n->as.binary.rhs);
      break;
    case AST_UNARY:
    case AST_RECV:
    case AST_AWAIT:
    case AST_GO:
      bindExpr(b, n->as.unary.operand);  // 载荷复用（op==0）；await 位置检查 Task 4
      break;
    case AST_TERNARY:
      bindExpr(b, n->as.ternary.cond);
      bindExpr(b, n->as.ternary.thenExpr);
      bindExpr(b, n->as.ternary.elseExpr);
      break;
    case AST_CALL:
      bindExpr(b, n->as.call.callee);
      for (int32_t i = 0; i < n->as.call.count; i++) {
        bindExpr(b, n->as.call.args[i]);
      }
      break;
    case AST_INDEX:
      bindExpr(b, n->as.indexExpr.obj);
      bindExpr(b, n->as.indexExpr.index);
      break;
    case AST_MEMBER:
      bindExpr(b, n->as.memberExpr.obj);
      break;
    case AST_SLICE:
      bindExpr(b, n->as.slice.obj);
      bindExpr(b, n->as.slice.start);
      bindExpr(b, n->as.slice.end);
      bindExpr(b, n->as.slice.step);
      break;
    case AST_COMPREHENSION:
    case AST_GEN_EXPR:
      bindCompr(b, n);
      break;
    case AST_FUNC_EXPR:
      bindFuncCommon(b, n, n->as.funcExpr.flags, n->as.funcExpr.params, n->as.funcExpr.paramCount,
                     n->as.funcExpr.body, n->as.funcExpr.exprBody);
      break;
    case AST_THIS:
    case AST_NIL:
    case AST_BOOL:
    case AST_INT:
    case AST_FLOAT:
    case AST_BIGINT:
    case AST_RUNE:
      break;
    default:
      break;
  }
}
```

```c
// u64 → 十进制数字串写入 out（返回长度；缓冲 ≥ 21）
static int32_t u64ToDec(char* out, ms_u64 v) {
  char tmp[20];
  int32_t n = 0;
  do {
    tmp[n++] = (char)('0' + (int)(v % 10));
    v /= 10;
  } while (v != 0);
  for (int32_t i = 0; i < n; i++) {
    out[i] = tmp[n - 1 - i];
  }
  return n;
}

// 节点改为 bigint 字面量：neg + 十进制幅度串（arena 分配）
static void setBigintMag(AstNode* n, AstArena* arena, bool neg, const char* mag, int32_t magLen) {
  char* s = astArenaAlloc(arena, (size_t)magLen + 2);
  int32_t len = 0;
  if (neg) {
    s[len++] = '-';
  }
  memcpy(s + len, mag, (size_t)magLen);
  len += magLen;
  s[len] = '\0';
  n->kind = AST_BIGINT;
  n->as.bigintLit.start = s;
  n->as.bigintLit.len = len;
}

static void setBigintU64(AstNode* n, AstArena* arena, bool neg, ms_u64 mag) {
  char buf[20];
  int32_t m = u64ToDec(buf, mag);
  setBigintMag(n, arena, neg, buf, m);
}

// 十进制幅度串乘法（schoolbook）；输入为无前导零数字串；结果 arena 分配
static const char* decMul(AstArena* arena, const char* a, int32_t alen, const char* b, int32_t blen,
                          int32_t* outLen) {
  int32_t rlen = alen + blen;
  int32_t* digits = malloc(sizeof(int32_t) * (size_t)rlen);  // 累加上限 ≈ 20*81，int32 充裕
  MS_ASSERT(digits != NULL);
  memset(digits, 0, sizeof(int32_t) * (size_t)rlen);
  for (int32_t i = alen - 1; i >= 0; i--) {
    for (int32_t j = blen - 1; j >= 0; j--) {
      digits[i + j + 1] += (a[i] - '0') * (b[j] - '0');
    }
  }
  for (int32_t i = rlen - 1; i > 0; i--) {
    digits[i - 1] += digits[i] / 10;
    digits[i] %= 10;
  }
  int32_t start = 0;
  while (start < rlen - 1 && digits[start] == 0) {
    start++;  // 去前导零（保留至少一位）
  }
  char* r = astArenaAlloc(arena, (size_t)(rlen - start) + 1);
  for (int32_t i = 0; i < rlen - start; i++) {
    r[i] = (char)('0' + digits[start + i]);
  }
  r[rlen - start] = '\0';
  free(digits);
  *outLen = rlen - start;
  return r;
}
```

```c
// i64 溢出受检运算（MSVC 无 __builtin 溢出内建，手写检查；乘法经 u64 回除校验）
static bool addOv(ms_i64 a, ms_i64 b, ms_i64* out) {
  if ((b > 0 && a > INT64_MAX - b) || (b < 0 && a < INT64_MIN - b)) {
    return true;
  }
  *out = a + b;
  return false;
}

static bool subOv(ms_i64 a, ms_i64 b, ms_i64* out) {
  if ((b < 0 && a > INT64_MAX + b) || (b > 0 && a < INT64_MIN + b)) {
    return true;
  }
  *out = a - b;
  return false;
}

static bool mulOv(ms_i64 a, ms_i64 b, ms_i64* out) {
  if (a == -1 && b == INT64_MIN) {
    return true;
  }
  ms_u64 w = (ms_u64)a * (ms_u64)b;  // 模 2^64 良定义
  ms_i64 s = (ms_i64)w;
  if (a != 0 && a != -1 && s / a != b) {
    return true;
  }
  *out = s;
  return false;
}

// 溢出路径：由操作数符号重建精确值（add/sub 经 u64 环绕恒精确；mul 走十进制）
static void foldBigintAdd(AstNode* n, AstArena* arena, ms_i64 a, ms_i64 b) {
  ms_u64 w = (ms_u64)a + (ms_u64)b;
  setBigintU64(n, arena, b < 0, b < 0 ? ~w + 1 : w);  // 下溢幅度 = 2^64 - w
}

static void foldBigintSub(AstNode* n, AstArena* arena, ms_i64 a, ms_i64 b) {
  ms_u64 w = (ms_u64)a - (ms_u64)b;
  setBigintU64(n, arena, b >= 0, b >= 0 ? ~w + 1 : w);
}

static void foldBigintMul(AstNode* n, AstArena* arena, ms_i64 a, ms_i64 b) {
  char buf[21];
  bool neg = (a < 0) != (b < 0);
  int32_t alen = u64ToDec(buf, a < 0 ? ~((ms_u64)a) + 1 : (ms_u64)a);
  char bmag[21];
  memcpy(bmag, buf, (size_t)alen);  // u64ToDec 只写 buf → 先复制 a 幅度再用 buf
  int32_t blen = u64ToDec(buf, b < 0 ? ~((ms_u64)b) + 1 : (ms_u64)b);
  int32_t rlen = 0;
  const char* r = decMul(arena, bmag, alen, buf, blen, &rlen);
  setBigintMag(n, arena, neg, r, rlen);
}

// int 幂：先走 i64 受检快路径，溢出再十进制连乘（e ∈ [0,1024] 且位数 ≤ 256 才折叠）
static void foldIntPow(AstNode* n, AstArena* arena, ms_i64 base, ms_i64 e) {
  if (e < 0 || e > 1024) {
    return;  // 负指数/巨幂留给运行时（float pow / bigint 精确运算 T016）
  }
  ms_i64 r = 1;
  ms_i64 b = base;
  ms_i64 k = e;
  bool ok = true;
  while (k > 0 && ok) {
    if ((k & 1) != 0) {
      ok = !mulOv(r, b, &r);
    }
    k >>= 1;
    if (ok && k > 0) {
      ok = !mulOv(b, b, &b);  // 平方底数（k 归零前最后一步可省）
    }
  }
  if (ok) {
    setIntLit(n, r);
    return;
  }
  char buf[21];
  int32_t baseLen = u64ToDec(buf, base < 0 ? ~((ms_u64)base) + 1 : (ms_u64)base);
  char baseMag[21];
  memcpy(baseMag, buf, (size_t)baseLen);
  const char* acc = "1";
  int32_t accLen = 1;
  for (ms_i64 i = 0; i < e; i++) {
    int32_t rlen = 0;
    const char* r = decMul(arena, acc, accLen, baseMag, baseLen, &rlen);
    if (rlen > 256) {
      return;  // 超出折叠预算：整体放弃（节点保持二元 **）
    }
    acc = r;
    accLen = rlen;
  }
  bool neg = base < 0 && (e % 2) == 1;
  setBigintMag(n, arena, neg, acc, accLen);
}
```

```c
static void tryFoldBinary(Binder* b, AstNode* n) {
  AstNode* lhs = n->as.binary.lhs;
  AstNode* rhs = n->as.binary.rhs;
  AstBinOp op = n->as.binary.op;
  bool bothInt = lhs->kind == AST_INT && rhs->kind == AST_INT;
  bool anyFloat = lhs->kind == AST_FLOAT || rhs->kind == AST_FLOAT;
  if (bothInt) {
    ms_i64 a = lhs->as.intLit.v;
    ms_i64 c = rhs->as.intLit.v;
    ms_i64 r = 0;
    switch (op) {
      case AST_OP_ADD:
        if (!addOv(a, c, &r)) setIntLit(n, r); else foldBigintAdd(n, b->arena, a, c);
        return;
      case AST_OP_SUB:
        if (!subOv(a, c, &r)) setIntLit(n, r); else foldBigintSub(n, b->arena, a, c);
        return;
      case AST_OP_MUL:
        if (!mulOv(a, c, &r)) setIntLit(n, r); else foldBigintMul(n, b->arena, a, c);
        return;
      case AST_OP_DIV:
        if (c == 0) return;  // 运行时 ArithmeticError
        if (a == INT64_MIN && c == -1) { setBigintU64(n, b->arena, false, (ms_u64)INT64_MAX + 1); return; }
        setIntLit(n, a / c);  // 截断除（02 §3.5）
        return;
      case AST_OP_MOD:
        if (c == 0) return;
        if (a == INT64_MIN && c == -1) { setIntLit(n, 0); return; }
        setIntLit(n, a % c);  // 符号随被除数
        return;
      case AST_OP_POW:

        return;
      case AST_OP_BIT_AND: setIntLit(n, a & c); return;
      case AST_OP_BIT_OR: setIntLit(n, a | c); return;
      case AST_OP_BIT_XOR: setIntLit(n, a ^ c); return;

      case AST_OP_LT: setBoolLit(n, a < c); return;
      case AST_OP_LE: setBoolLit(n, a <= c); return;
      case AST_OP_GT: setBoolLit(n, a > c); return;
      case AST_OP_GE: setBoolLit(n, a >= c); return;

    double c = rhs->kind == AST_FLOAT ? rhs->as.floatLit.v : (double)rhs->as.intLit.v;
```

```c
static const char* assignOpName(AstBinOp op) {
  switch (op) {
    case AST_OP_ADD: return "+=";
    case AST_OP_SUB: return "-=";
    case AST_OP_MUL: return "*=";
    case AST_OP_DIV: return "/=";
    case AST_OP_MOD: return "%=";

    case AST_OP_BIT_XOR: return "^=";
    case AST_OP_SHL: return "<<=";
    case AST_OP_SHR: return ">>=";
    default: return "=";
  }

static void dumpAnn(FILE* out, const AstNode* n) {
  if (n->bindKind == AST_BIND_NONE) {
    return;
  }
  fputs(" [", out);
  if (n->bindKind == AST_BIND_LOCAL) {
    fprintf(out, "local:%d", n->bindSlot);
  } else if (n->bindKind == AST_BIND_GLOBAL) {
    fputs("global", out);
  } else {
    fprintf(out, "upvalue:%d.%d", n->bindUpvalDepth, n->bindSlot);
  }
  if ((n->bindFlags & AST_BIND_FRESH) != 0) {
    fputs(" fresh", out);
  }
  fputc(']', out);
}

static void dumpName(FILE* out, const char* name, int32_t len) { fprintf(out, "%.*s", (int)len, name); }

static void dumpEscaped(FILE* out, const char* s, int32_t len) {
  fputc('"', out);
  for (int32_t i = 0; i < len; i++) {
    unsigned char c = (unsigned char)s[i];
    switch (c) {
      case '\\': fputs("\\\\", out); break;
      case '"': fputs("\\\"", out); break;
      case '\n': fputs("\\n", out); break;
      case '\t': fputs("\\t", out); break;
      case '\r': fputs("\\r", out); break;
      default:
        if (c < 0x20) {
          fprintf(out, "\\x%02x", c);
        } else {
          fputc((char)c, out);  // UTF-8 原样
        }
        break;
    }
  }
  fputc('"', out);
}

static void dumpFloat(FILE* out, double v) {
  char buf[40];
  snprintf(buf, sizeof(buf), "%.17g", v);
  fputs(buf, out);
  if (strpbrk(buf, ".eEin") == NULL) {  // "inf"/"nan" 判定外，补 .0 保持 float 可辨识
    fputs(".0", out);
  }
}

static void dumpNode(FILE* out, const AstNode* n, int depth);

static void dumpIndent(FILE* out, int depth) {
  for (int i = 0; i < depth; i++) {
    fputs("  ", out);
  }
}

// 头行：多行模式缩进 + (head；内联模式无缩进
static void dumpHead(FILE* out, int depth, const char* head) {
  if (depth >= 0) {
    dumpIndent(out, depth);
  }
  fprintf(out, "(%s", head);
}

// 子节点分隔：内联空格，多行换行（子节点自带缩进）
static void dumpSep(FILE* out, bool inlineMode) { fputs(inlineMode ? " " : "\n", out); }

// 多行节点闭合；hadKids=已输出子节点（其末自带换行）→ 闭合行需缩进；否则与头同行
static void dumpClose(FILE* out, int depth, bool inlineMode, bool hadKids) {
  if (hadKids && !inlineMode) dumpIndent(out, depth);
  fputc(')', out);
  if (!inlineMode) fputc('\n', out);
}

// 单行节点闭合
static void dumpCloseLine(FILE* out, bool inlineMode) {
  fputc(')', out);
  if (!inlineMode) fputc('\n', out);
}

// 子节点序列：数组形式，逐个前缀分隔符
static void dumpKidSeq(FILE* out, bool inlineMode, int depth, AstNode** kids, int32_t count) {
  for (int32_t i = 0; i < count; i++) {
    dumpSep(out, inlineMode);
    dumpNode(out, kids[i], depth >= 0 ? depth + 1 : -1);
  }
}
```

```c
static void dumpNode(FILE* out, const AstNode* n, int depth) {
  if (n == NULL) {
    if (depth >= 0) dumpIndent(out, depth);
    fputs("(_)\n", out);  // 占位：BAD_TARGET 等已诊断缺省
    return;
  }
  bool inlineMode = depth < 0;
  switch (n->kind) {
    case AST_MODULE:
    case AST_BLOCK:
      dumpHead(out, depth, n->kind == AST_MODULE ? "module" : "block");
      dumpKidSeq(out, inlineMode, depth, n->as.list.items, n->as.list.count);
      dumpClose(out, depth, inlineMode, n->as.list.count > 0);
      break;
    case AST_VAR_DECL: {
      char head[24];
      const char* base = "var";
      if ((n->as.varDecl.flags & AST_VAR_SHORT) != 0) {
        base = "short";
      } else if ((n->as.varDecl.flags & AST_VAR_CONST) != 0) {
        base = "const";
      }
      if ((n->as.varDecl.flags & AST_VAR_STATIC) != 0) {
        snprintf(head, sizeof(head), "static %s", base);
      } else {
        snprintf(head, sizeof(head), "%s", base);
      }
      dumpHead(out, depth, head);
      fputc(' ', out);
      dumpName(out, n->as.varDecl.name, n->as.varDecl.nameLen);
      dumpAnn(out, n);
      if (n->as.varDecl.init != NULL) {
        dumpSep(out, inlineMode);
        dumpNode(out, n->as.varDecl.init, depth >= 0 ? depth + 1 : -1);
      }
      dumpClose(out, depth, inlineMode, n->as.varDecl.init != NULL);
      break;
    }
    case AST_ASSIGN:
      dumpHead(out, depth, "assign");
      fprintf(out, " %s", assignOpName(n->as.assign.op));
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.assign.target, depth >= 0 ? depth + 1 : -1);
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.assign.value, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    case AST_DESTRUCTURE: {
      dumpHead(out, depth, "destructure (");
      for (int32_t i = 0; i < n->as.destructure.count; i++) {
        const AstNode* t = n->as.destructure.targets[i];
        if (i > 0) {
          fputc(' ', out);
        }
        if (i == n->as.destructure.restIndex) {
          fputc('*', out);
        }
        if (t == NULL) {
          fputc('_', out);
        } else {
          dumpName(out, t->as.ident.name, t->as.ident.nameLen);
          dumpAnn(out, t);
        }
      }
      fputc(')', out);
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.destructure.value, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    }
    case AST_EXPR_STMT:
      dumpHead(out, depth, "expr");
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.exprStmt.expr, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    case AST_IF:
      dumpHead(out, depth, "if");
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.ifStmt.cond, depth >= 0 ? depth + 1 : -1);
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.ifStmt.thenBlock, depth >= 0 ? depth + 1 : -1);
      if (n->as.ifStmt.elseNode != NULL) {
        dumpSep(out, inlineMode);
        dumpNode(out, n->as.ifStmt.elseNode, depth >= 0 ? depth + 1 : -1);
      }
      dumpClose(out, depth, inlineMode, true);
      break;
    case AST_FOR: {
      const char* head = n->as.forStmt.form == AST_FOR_TRI   ? "for-tri"
                         : n->as.forStmt.form == AST_FOR_IN  ? "for-in"
                         : n->as.forStmt.form == AST_FOR_COND ? "for-cond"
                                                             : "for-inf";
      dumpHead(out, depth, head);
      if (n->as.forStmt.form == AST_FOR_IN) {
        const AstNode* t = n->as.forStmt.target;
        if (t == NULL) {
          fputs(" _", out);
        } else if (t->kind == AST_TUPLE) {
          fputs(" (", out);
          for (int32_t i = 0; i < t->as.tuple.count; i++) {
            if (i > 0) {
              fputc(' ', out);
            }
            dumpName(out, t->as.tuple.items[i]->as.ident.name, t->as.tuple.items[i]->as.ident.nameLen);
            dumpAnn(out, t->as.tuple.items[i]);
          }
          fputc(')', out);
        } else {
          fputc(' ', out);
          dumpName(out, t->as.ident.name, t->as.ident.nameLen);
          dumpAnn(out, t);
        }
      } else if (n->as.forStmt.form != AST_FOR_INF) {
        const AstNode* parts[3] = {n->as.forStmt.init, n->as.forStmt.cond, n->as.forStmt.post};
        int partsCount = n->as.forStmt.form == AST_FOR_COND ? 1 : 3;
        for (int i = 0; i < partsCount; i++) {
          if (parts[i] == NULL) {
            fputs(" _", out);
          } else {
            fputc(' ', out);
            dumpNode(out, parts[i], -1);
          }
        }
      }
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.forStmt.body, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    }
    case AST_WHILE:
      dumpHead(out, depth, "while");
      fputc(' ', out);
      dumpNode(out, n->as.whileStmt.cond, -1);
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.whileStmt.body, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    case AST_SWITCH: {
      dumpHead(out, depth, n->as.switchStmt.isType ? "switch-type" : "switch");
      fputc(' ', out);
      dumpNode(out, n->as.switchStmt.subject, -1);
      for (int32_t i = 0; i < n->as.switchStmt.count; i++) {
        const AstNode* c = n->as.switchStmt.cases[i];
        dumpSep(out, inlineMode);
        if (depth >= 0) dumpIndent(out, depth + 1);
        if (c->as.switchCase.isDefault) {
          fputs("(default", out);
        } else {
          fputs("(case", out);
          for (int32_t v = 0; v < c->as.switchCase.valueCount; v++) {
            fputc(' ', out);
            dumpNode(out, c->as.switchCase.values[v], -1);
          }
          if (c->as.switchCase.bindName != NULL) {
            fputs(" as ", out);
            dumpName(out, c->as.switchCase.bindName, c->as.switchCase.bindLen);
          }
        }
        dumpSep(out, inlineMode);
        dumpNode(out, c->as.switchCase.body, depth >= 0 ? depth + 2 : -1);
        dumpClose(out, depth + 1, inlineMode, true);
      }
      dumpClose(out, depth, inlineMode, n->as.switchStmt.count > 0);
      break;
    }
    case AST_BREAK:
      dumpHead(out, depth, "break");
      dumpCloseLine(out, inlineMode);
      break;
    case AST_CONTINUE:
      dumpHead(out, depth, "continue");
      dumpCloseLine(out, inlineMode);
      break;
    case AST_RETURN:
    case AST_THROW:
    case AST_YIELD: {
      const char* head = n->kind == AST_RETURN ? "return" : n->kind == AST_THROW ? "throw" : "yield";
      dumpHead(out, depth, head);
      if (n->as.exprStmt.expr != NULL) {
        dumpSep(out, inlineMode);
        dumpNode(out, n->as.exprStmt.expr, depth >= 0 ? depth + 1 : -1);
      }
      if (n->as.exprStmt.expr != NULL) {
        dumpClose(out, depth, inlineMode, true);
      } else {
        dumpCloseLine(out, inlineMode);
      }
      break;
    }
    case AST_DEFER:
      dumpHead(out, depth, "defer");
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.exprStmt.expr, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    case AST_SEND:
      dumpHead(out, depth, "send");
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.sendStmt.chan, depth >= 0 ? depth + 1 : -1);
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.sendStmt.value, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    case AST_SELECT: {
      dumpHead(out, depth, "select");
      for (int32_t i = 0; i < n->as.selectStmt.count; i++) {
        const AstNode* c = n->as.selectStmt.cases[i];
        dumpSep(out, inlineMode);
        if (depth >= 0) dumpIndent(out, depth + 1);
        if (c->as.selectCase.form == AST_SEL_DEFAULT) {
          fputs("(default", out);
        } else {
          fputs(c->as.selectCase.form == AST_SEL_RECV ? "(recv" : "(send", out);
          if (c->as.selectCase.form == AST_SEL_RECV && c->as.selectCase.target != NULL) {
            fputc(' ', out);
            dumpNode(out, c->as.selectCase.target, -1);
          }
          fputc(' ', out);
          dumpNode(out, c->as.selectCase.chan, -1);
          if (c->as.selectCase.form == AST_SEL_SEND) {
            fputc(' ', out);
            dumpNode(out, c->as.selectCase.value, -1);
          }
        }
        dumpSep(out, inlineMode);
        dumpNode(out, c->as.selectCase.body, depth >= 0 ? depth + 2 : -1);
        dumpClose(out, depth + 1, inlineMode, true);
      }
      dumpClose(out, depth, inlineMode, n->as.selectStmt.count > 0);
      break;
    }
    case AST_IMPORT: {
      dumpHead(out, depth, "import");
      fputc(' ', out);
      dumpEscaped(out, n->as.importStmt.path, n->as.importStmt.pathLen);
      if (n->as.importStmt.alias != NULL) {
        fputs(" as ", out);
        dumpName(out, n->as.importStmt.alias, n->as.importStmt.aliasLen);
      } else if (n->as.importStmt.star) {
        fputs(" *", out);
      } else if (n->as.importStmt.names != NULL) {
        fputs(" {", out);
        for (int32_t i = 0; i < n->as.importStmt.nameCount; i++) {
          const AstImportName* nm = &n->as.importStmt.names[i];
          if (i > 0) {
            fputs(", ", out);
          }
          dumpName(out, nm->name, nm->nameLen);
          if (nm->asName != NULL) {
            fputs(" as ", out);
            dumpName(out, nm->asName, nm->asLen);
          }
        }
        fputs("}", out);
      }
      dumpCloseLine(out, inlineMode);
      break;
    }
    case AST_FUNC_DECL:
    case AST_FUNC_EXPR: {
      // funcDecl/funcExpr 载荷字段同名，按 kind 取用
      const char* name = n->kind == AST_FUNC_DECL ? n->as.funcDecl.name : NULL;
      int32_t nameLen = n->kind == AST_FUNC_DECL ? n->as.funcDecl.nameLen : 0;
      ms_u8 flags = n->kind == AST_FUNC_DECL ? n->as.funcDecl.flags : n->as.funcExpr.flags;
      dumpHead(out, depth, n->kind == AST_FUNC_DECL ? "func-decl" : "func-expr");
      if (name != NULL) {
        fputc(' ', out);
        dumpName(out, name, nameLen);
        dumpAnn(out, n);
      }
      if ((flags & AST_FUNC_ASYNC) != 0) {
        fputs(" async", out);
      }
      if ((flags & AST_FUNC_GENERATOR) != 0) {
        fputs(" generator", out);
      }
      if ((flags & AST_FUNC_STATIC) != 0) {
        fputs(" static", out);
      }
      dumpSep(out, inlineMode);
      if (depth >= 0) dumpIndent(out, depth + 1);
      dumpParams(out, n->kind == AST_FUNC_DECL ? n->as.funcDecl.params : n->as.funcExpr.params,
                 n->kind == AST_FUNC_DECL ? n->as.funcDecl.paramCount : n->as.funcExpr.paramCount);
      if (!inlineMode) {
        fputc('\n', out);
      }
      AstNode* body = n->kind == AST_FUNC_DECL ? n->as.funcDecl.body : n->as.funcExpr.body;
      AstNode* exprBody = n->kind == AST_FUNC_DECL ? n->as.funcDecl.exprBody : n->as.funcExpr.exprBody;
      AstNode* tail = body != NULL ? body : exprBody;
      if (tail != NULL) {
        if (inlineMode) {
          fputc(' ', out);
        }
        dumpNode(out, tail, depth >= 0 ? depth + 1 : -1);
      }
      dumpClose(out, depth, inlineMode, true);
      break;
    }
    case AST_CLASS_DECL: {
      dumpHead(out, depth, n->as.classDecl.isTrait ? "trait-decl" : "class-decl");
      fputc(' ', out);
      dumpName(out, n->as.classDecl.name, n->as.classDecl.nameLen);
      dumpAnn(out, n);
      if (n->as.classDecl.baseCount > 0) {
        fputs(" (bases", out);
        for (int32_t i = 0; i < n->as.classDecl.baseCount; i++) {
          fputc(' ', out);
          dumpName(out, n->as.classDecl.bases[i]->as.ident.name,
                   n->as.classDecl.bases[i]->as.ident.nameLen);
        }
        fputc(')', out);
      }
      dumpKidSeq(out, inlineMode, depth, n->as.classDecl.members, n->as.classDecl.memberCount);
      dumpClose(out, depth, inlineMode, n->as.classDecl.memberCount > 0);
      break;
    }
    case AST_TRY: {
      dumpHead(out, depth, "try");
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.tryStmt.tryBlock, depth >= 0 ? depth + 1 : -1);
      for (int32_t i = 0; i < n->as.tryStmt.catchCount; i++) {
        const AstCatchClause* c = &n->as.tryStmt.catches[i];
        dumpSep(out, inlineMode);
        if (depth >= 0) dumpIndent(out, depth + 1);
        fputs("(catch", out);
        if (c->typeCount > 0) {
          fputs(" (", out);
          for (int32_t t = 0; t < c->typeCount; t++) {
            if (t > 0) {
              fputc(' ', out);
            }
            dumpName(out, c->types[t]->as.ident.name, c->types[t]->as.ident.nameLen);
          }
          fputc(')', out);
        }
        if (c->bindName != NULL) {
          fputc(' ', out);
          dumpName(out, c->bindName, c->bindLen);
        }
        dumpSep(out, inlineMode);
        dumpNode(out, c->block, depth >= 0 ? depth + 2 : -1);
        dumpClose(out, depth + 1, inlineMode, true);
      }
      if (n->as.tryStmt.finallyBlock != NULL) {
        dumpSep(out, inlineMode);
        if (depth >= 0) dumpIndent(out, depth + 1);
        fputs("(finally", out);
        dumpSep(out, inlineMode);
        dumpNode(out, n->as.tryStmt.finallyBlock, depth >= 0 ? depth + 2 : -1);
        dumpClose(out, depth + 1, inlineMode, true);
      }
      dumpClose(out, depth, inlineMode, true);
      break;
    }
    // ---------------- 表达式 ----------------
    case AST_IDENT:
      dumpHead(out, depth, "ident");
      fputc(' ', out);
      dumpName(out, n->as.ident.name, n->as.ident.nameLen);
      dumpAnn(out, n);
      dumpCloseLine(out, inlineMode);
      break;
    case AST_THIS:
      dumpHead(out, depth, "this");
      dumpCloseLine(out, inlineMode);
      break;
    case AST_NIL:
      dumpHead(out, depth, "nil");
      dumpCloseLine(out, inlineMode);
      break;
    case AST_BOOL:
      dumpHead(out, depth, "bool");
      fprintf(out, " %s", n->as.boolLit.b ? "true" : "false");
      dumpCloseLine(out, inlineMode);
      break;
    case AST_INT:
      dumpHead(out, depth, "int");
      fprintf(out, " %lld", (long long)n->as.intLit.v);
      dumpCloseLine(out, inlineMode);
      break;
    case AST_FLOAT:
      dumpHead(out, depth, "float");
      fputc(' ', out);
      dumpFloat(out, n->as.floatLit.v);
      dumpCloseLine(out, inlineMode);
      break;
    case AST_BIGINT:
      dumpHead(out, depth, "bigint");
      fputc(' ', out);
      dumpEscaped(out, n->as.bigintLit.start, n->as.bigintLit.len);
      dumpCloseLine(out, inlineMode);
      break;
    case AST_RUNE:
      dumpHead(out, depth, "rune");
      fprintf(out, " U+%04X", n->as.runeLit.cp);
      dumpCloseLine(out, inlineMode);
      break;
    case AST_STRING:
      if (n->as.strLit.raw) {
        dumpHead(out, depth, "string raw");
        fputc(' ', out);
        dumpEscaped(out, n->as.strLit.segs[0].start, n->as.strLit.segs[0].len);
        dumpCloseLine(out, inlineMode);
        break;
      }
      dumpHead(out, depth, "string");
      for (int32_t i = 0; i < n->as.strLit.count; i++) {
        const AstStrSeg* seg = &n->as.strLit.segs[i];
        dumpSep(out, inlineMode);
        if (depth >= 0) dumpIndent(out, depth + 1);
        if (seg->expr == NULL) {
          fputs("(lit ", out);
          dumpEscaped(out, seg->start, seg->len);
          fputc(')', out);
          if (!inlineMode) fputc('\n', out);
        } else {
          fputs("(interp", out);
          dumpSep(out, inlineMode);
          dumpNode(out, seg->expr, depth >= 0 ? depth + 2 : -1);
          dumpClose(out, depth + 1, inlineMode, true);
        }
      }
      dumpClose(out, depth, inlineMode, true);  // 串段恒 ≥1
      break;
    case AST_TUPLE:
    case AST_LIST:
    case AST_SET:
      dumpHead(out, depth,
               n->kind == AST_TUPLE ? "tuple" : n->kind == AST_LIST ? "list" : "set");
      dumpKidSeq(out, inlineMode, depth, n->as.list.items, n->as.list.count);
      dumpClose(out, depth, inlineMode, n->as.list.count > 0);
      break;
    case AST_MAP:
      dumpHead(out, depth, "map");
      for (int32_t i = 0; i < n->as.mapLit.count; i++) {
        dumpSep(out, inlineMode);
        if (depth >= 0) dumpIndent(out, depth + 1);
        fputs("(entry", out);
        fputc(' ', out);
        dumpNode(out, n->as.mapLit.keys[i], -1);
        fputc(' ', out);
        dumpNode(out, n->as.mapLit.values[i], -1);
        fputc(')', out);
        if (!inlineMode) fputc('\n', out);
      }
      dumpClose(out, depth, inlineMode, n->as.mapLit.count > 0);
      break;
    case AST_BINARY:
      dumpHead(out, depth, "binary");
      fprintf(out, " %s", binOpName(n->as.binary.op));
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.binary.lhs, depth >= 0 ? depth + 1 : -1);
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.binary.rhs, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    case AST_LOGIC:
      dumpHead(out, depth, n->as.binary.op == AST_OP_AND ? "and" : "or");
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.binary.lhs, depth >= 0 ? depth + 1 : -1);
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.binary.rhs, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    case AST_UNARY: {
      const char* head = n->as.unary.op == AST_UNOP_NEG   ? "neg"
                         : n->as.unary.op == AST_UNOP_NOT ? "not"
                                                          : "inv";
      dumpHead(out, depth, head);
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.unary.operand, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    }
    case AST_RECV:
    case AST_AWAIT:
    case AST_GO:
      dumpHead(out, depth, n->kind == AST_RECV ? "recv" : n->kind == AST_AWAIT ? "await" : "go");
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.unary.operand, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    case AST_TERNARY:
      dumpHead(out, depth, "ternary");
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.ternary.cond, depth >= 0 ? depth + 1 : -1);
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.ternary.thenExpr, depth >= 0 ? depth + 1 : -1);
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.ternary.elseExpr, depth >= 0 ? depth + 1 : -1);
      dumpClose(out, depth, inlineMode, true);
      break;
    case AST_CALL: {
      dumpHead(out, depth, "call");
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.call.callee, depth >= 0 ? depth + 1 : -1);
      for (int32_t i = 0; i < n->as.call.count; i++) {
        dumpSep(out, inlineMode);
        if (depth >= 0) dumpIndent(out, depth + 1);
        if (n->as.call.spread != NULL && n->as.call.spread[i]) {
          fputs("(spread", out);
          dumpSep(out, inlineMode);
          dumpNode(out, n->as.call.args[i], depth >= 0 ? depth + 2 : -1);
          dumpClose(out, depth + 1, inlineMode, true);
        } else {
          dumpNode(out, n->as.call.args[i], depth + 1);
        }
      }
      dumpClose(out, depth, inlineMode, true);
      break;
    }
    case AST_INDEX:
      dumpHead(out, depth, "index");
      fputc(' ', out);
      dumpNode(out, n->as.indexExpr.obj, -1);
      fputc(' ', out);
      dumpNode(out, n->as.indexExpr.index, -1);
      dumpCloseLine(out, inlineMode);
      break;
    case AST_MEMBER:
      dumpHead(out, depth, "member");
      fputc(' ', out);
      dumpNode(out, n->as.memberExpr.obj, -1);
      fputc(' ', out);
      dumpName(out, n->as.memberExpr.name, n->as.memberExpr.nameLen);
      dumpCloseLine(out, inlineMode);
      break;
    case AST_SLICE: {
      dumpHead(out, depth, "slice");
      fputc(' ', out);
      dumpNode(out, n->as.slice.obj, -1);
      const AstNode* parts[3] = {n->as.slice.start, n->as.slice.end, n->as.slice.step};
      for (int i = 0; i < 3; i++) {
        fputc(' ', out);
        if (parts[i] == NULL) {
          fputc('_', out);
        } else {
          dumpNode(out, parts[i], -1);
        }
      }
      dumpCloseLine(out, inlineMode);
      break;
    }
    case AST_COMPREHENSION:
    case AST_GEN_EXPR: {
      const char* head = "gen-expr";
      if (n->kind == AST_COMPREHENSION) {
        head = n->as.compr.compKind == AST_COMP_LIST ? "comp-list"
               : n->as.compr.compKind == AST_COMP_MAP ? "comp-map"
                                                          : "comp-set";
      }
      dumpHead(out, depth, head);
      if (n->kind == AST_COMPREHENSION && n->as.compr.compKind == AST_COMP_MAP) {
        dumpSep(out, inlineMode);
        dumpNode(out, n->as.compr.key, depth >= 0 ? depth + 1 : -1);
      }
      dumpSep(out, inlineMode);
      dumpNode(out, n->as.compr.value, depth >= 0 ? depth + 1 : -1);
      // for/if 子句（多行：每条一行；内联：单行拼接）
      for (int32_t i = 0; i < n->as.compr.forCount; i++) {
        dumpSep(out, inlineMode);
        if (depth >= 0) dumpIndent(out, depth + 1);
        fputs("(for (", out);
        const AstNode* t = n->as.compr.fors[i].target;
        if (t == NULL) {
          fputc('_', out);
        } else if (t->kind == AST_TUPLE) {
          for (int32_t j = 0; j < t->as.tuple.count; j++) {
            if (j > 0) fputc(' ', out);
            dumpName(out, t->as.tuple.items[j]->as.ident.name, t->as.tuple.items[j]->as.ident.nameLen);
            dumpAnn(out, t->as.tuple.items[j]);
          }
        } else {
          dumpName(out, t->as.ident.name, t->as.ident.nameLen);
          dumpAnn(out, t);
        }
        fputs(") ", out);
        dumpNode(out, n->as.compr.fors[i].iter, -1);
        dumpCloseLine(out, inlineMode);
      }
      for (int32_t i = 0; i < n->as.compr.condCount; i++) {
        dumpSep(out, inlineMode);
        if (depth >= 0) dumpIndent(out, depth + 1);
        fputs("(if ", out);
        dumpNode(out, n->as.compr.conds[i], -1);
        dumpCloseLine(out, inlineMode);
      }
      dumpClose(out, depth, inlineMode, true);
      break;
    }
    default:
      dumpHead(out, depth, "?");
      dumpCloseLine(out, inlineMode);
      break;
  }
}

void astDumpModule(const AstNode* module, FILE* out) { dumpNode(out, module, 0); }
```

```c
static AstNode* frontEnd(const char* src, int32_t len, const char* path, AstArena* arena,

  Parser p;
  parserInit(&p, src, len, path, arena, diags);
```

```python
#!/usr/bin/env python3
"""Generate or check `ms --dump-ast` snapshot baselines (.ast) for conformance cases.

Baselines are test assets: regenerate only via this tool (never hand-edit).
Usage:
  python tools/gen_ast_snapshots.py <ms-exe> <case.ms> [<case.ms> ...]          # write .ast
  python tools/gen_ast_snapshots.py --check <ms-exe> <case.ms> [<case.ms> ...]  # verify, exit 1 on diff
"""

from __future__ import annotations

import argparse
import subprocess
import sys
from pathlib import Path


def dump_bytes(ms_exe: Path, case: Path) -> bytes:
    proc = subprocess.run(
        [str(ms_exe), "--dump-ast", str(case)], capture_output=True, check=False
    )
    if proc.returncode != 0:
        raise SystemExit(
            f"{case}: ms exited {proc.returncode}\n{proc.stderr.decode(errors='replace')}"
        )
    return proc.stdout.replace(b"\r\n", b"\n")


def main() -> int:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--check", action="store_true", help="compare instead of writing")
    parser.add_argument("ms_exe", type=Path)
    parser.add_argument("cases", type=Path, nargs="+")
    args = parser.parse_args()
    mismatch = 0
    for case in args.cases:
        snapshot = case.with_suffix(".ast")
        output = dump_bytes(args.ms_exe, case)
        if args.check:
            if not snapshot.exists():
                print(f"MISSING {snapshot}")
                mismatch += 1
            elif snapshot.read_bytes() != output:
                print(f"MISMATCH {snapshot}")
                mismatch += 1
        else:
            snapshot.write_bytes(output)
            print(f"wrote {snapshot}")
    if args.check and mismatch == 0:
        print(f"ok: {len(args.cases)} snapshots match")
    return 1 if mismatch else 0


if __name__ == "__main__":
    sys.exit(main())
```
