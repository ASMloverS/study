# T011 VM 基础：dispatch 循环与控制流 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现栈式 VM 核心（dispatch 双路径、值栈、模块帧、全局表、算术/比较、print/range 最小内置）与 if/for/while/break/continue/switch 控制流编译，达成 `print 1+2` → `3` 门禁。

**Architecture:** 单帧执行模块 chunk；MsValue 为无堆 tagged-struct（T012 接堆）；dispatch 以 `MS_USE_COMPUTED_GOTO` 宏分叉出 computed-goto / switch 两套展开、共享同一指令处理体；运行时错误走"错误槽 + 统一 unwind"（28 §6）；控制流全部编译为 JMP 族比较链（SWITCH_TABLE 跳转表优化后置）。

**Tech Stack:** C11（MSVC /W4 /WX + GCC/Clang -Wall -Wextra -Werror -Wshadow）、CMake ≥3.16、ctest。

**分支:** `feature/t011-vm-basic`（已创建）。构建：`cmake --build build --config Debug`；测试：`ctest --test-dir build -C Debug`。

**关键语义决定（设计文档依据）:**

- 真值：仅 `false`/`nil` 为假，`0`/`""` 为真（02 §2）。
- `/`：int 截断除法（`-7/2 == -3`），除零 → ArithmeticError；`%` 符号随被除数，模零 → ArithmeticError（02 §3.5）。
- bool 与 int 不互转：`1 == true` 为 false；`1 == 1.0` 数值比较为 true（02 §2）。
- int 溢出为运行时错误占位（OverflowError；bigint 升级归 T016）。
- `&&`/`||` 返回操作数本身（短路经 JMP 族，值栈传值）。
- print：空格连接 + 换行；本任务 str 形态 nil/bool/int/float/string（字符串为常量池借用原文，转义解码归 T013，fixtures 避免转义序列）。
- for-in 本任务仅 range（最小 C 迭代器，迭代协议归 T017）。
- 值 switch / 类型 switch 均编译为比较链；类型式用 `CHECK_TYPE <const name>`（弹值压 bool，内置类型名匹配；class 归 T020 后补）。
- `CHECK_SAFEPOINT` 实现为预算递减 NOP；**编译器本任务不发射**（保持 T010 conformance .bc 基线不变，发射随 T029 抢占接入）。
- 退出码：编译错 3、运行时错误 1（27 §10）；运行时错误输出 `<file>:<line>: <Type>: <msg>` 到 stderr。
- 追加 binder 标注：类型 switch `as` 绑定写 case 节点 bindKind/bindSlot（编译器落 STORE_LOCAL / DEF+STORE_GLOBAL）。

```c
// 值操作助手（T011）：构造/真值/相等/排序/类型名/str 形态/浮点格式
#include "vm/vm.h"

#include <math.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

MsValue msValueNil(void) {
  MsValue v = {MS_VAL_NIL, {0}};
  return v;
}

MsValue msValueBool(bool b) {
  MsValue v = {MS_VAL_BOOL, {0}};
  v.as.b = b;
  return v;
}

MsValue msValueInt(ms_i64 i) {
  MsValue v = {MS_VAL_INT, {0}};
  v.as.i = i;
  return v;
}

MsValue msValueFloat(double f) {
  MsValue v = {MS_VAL_FLOAT, {0}};
  v.as.f = f;
  return v;
}

static bool isNumeric(const MsValue* v) { return v->kind == MS_VAL_INT || v->kind == MS_VAL_FLOAT; }

bool msValueIsTruthy(const MsValue* v) {
  if (v->kind == MS_VAL_BOOL) {
    return v->as.b;
  }
  return v->kind != MS_VAL_NIL;  // 其余（含 0/""/迭代器）均为真（02 §2）
}

bool msValueEqual(const MsValue* a, const MsValue* b) {
  if (isNumeric(a) && isNumeric(b)) {  // 数值塔：int/float 数值互比；bool 不参与
    if (a->kind == MS_VAL_INT && b->kind == MS_VAL_INT) {
      return a->as.i == b->as.i;
    }
    double da = a->kind == MS_VAL_INT ? (double)a->as.i : a->as.f;
    double db = b->kind == MS_VAL_INT ? (double)b->as.i : b->as.f;
    return da == db;
  }
  switch (a->kind) {
    case MS_VAL_NIL:
      return b->kind == MS_VAL_NIL;
    case MS_VAL_BOOL:
      return b->kind == MS_VAL_BOOL && a->as.b == b->as.b;
    case MS_VAL_STRING:
      return b->kind == MS_VAL_STRING && a->as.str.len == b->as.str.len &&
             memcmp(a->as.str.bytes, b->as.str.bytes, (size_t)a->as.str.len) == 0;
    case MS_VAL_FUNCTION:
      return b->kind == MS_VAL_FUNCTION && a->as.func == b->as.func;
    case MS_VAL_NATIVE:
      return b->kind == MS_VAL_NATIVE && a->as.native == b->as.native;
    default:
      return false;  // 迭代器等仅同一性；对象等价 T012 起接入
  }
}

bool msValueOrder(const MsValue* a, const MsValue* b, int32_t* outCmp) {
  if (!(isNumeric(a) && isNumeric(b))) {
    return false;  // 本任务仅数值有序（string 序比较后置）
  }
  if (a->kind == MS_VAL_INT && b->kind == MS_VAL_INT) {
    *outCmp = a->as.i < b->as.i ? -1 : (a->as.i > b->as.i ? 1 : 0);
    return true;
  }
  double da = a->kind == MS_VAL_INT ? (double)a->as.i : a->as.f;
  double db = b->kind == MS_VAL_INT ? (double)b->as.i : b->as.f;
  *outCmp = da < db ? -1 : (da > db ? 1 : 0);
  return true;
}

const char* msValueTypeName(const MsValue* v) {
  switch (v->kind) {
    case MS_VAL_NIL:
      return "nil";
    case MS_VAL_BOOL:
      return "bool";
    case MS_VAL_INT:
      return "int";
    case MS_VAL_FLOAT:
      return "float";
    case MS_VAL_STRING:
      return "string";
    case MS_VAL_FUNCTION:
    case MS_VAL_NATIVE:
      return "function";
    case MS_VAL_RANGE_ITER:
      return "iterator";
  }
  return "unknown";
}

void msFormatFloat(char* buf, size_t cap, double v) {
  if (isnan(v)) {
    snprintf(buf, cap, "nan");
    return;
  }
  if (isinf(v)) {
    snprintf(buf, cap, v < 0 ? "-inf" : "inf");
    return;
  }
  char tmp[40];
  int prec = 17;
  for (int p = 1; p <= 17; p++) {  // 最短往返位数
    snprintf(tmp, sizeof(tmp), "%.*g", p, v);
    if (strtod(tmp, NULL) == v) {
      prec = p;
      break;
    }
  }
  snprintf(tmp, sizeof(tmp), "%.*g", prec, v);
  const char* e = strchr(tmp, 'e');
  if (e != NULL) {  // 温和量级展开为定点（Python 形态：仅 exp < -4 或 ≥ 16 用科学计数）
    int exp10 = atoi(e + 1);
    if (exp10 >= -4 && exp10 < 16) {
      int digitsAfter = prec - 1 - exp10;
      if (digitsAfter < 0) {
        digitsAfter = 0;
      }
      snprintf(buf, cap, "%.*f", digitsAfter, v);
      if (strchr(buf, '.') == NULL) {
        size_t len = strlen(buf);
        snprintf(buf + len, cap - len, ".0");
      }
      return;
    }
  }
  snprintf(buf, cap, "%s", tmp);
  if (strpbrk(buf, ".eE") == NULL) {  // 整值浮点保 ".0"
    size_t len = strlen(buf);
    snprintf(buf + len, cap - len, ".0");
  }
}

void msValueToStr(const MsValue* v, char* buf, size_t cap) {
  switch (v->kind) {
    case MS_VAL_NIL:
      snprintf(buf, cap, "nil");
      break;
    case MS_VAL_BOOL:
      snprintf(buf, cap, v->as.b ? "true" : "false");
      break;
    case MS_VAL_INT:
      snprintf(buf, cap, "%lld", (long long)v->as.i);
      break;
    case MS_VAL_FLOAT:
      msFormatFloat(buf, cap, v->as.f);
      break;
    case MS_VAL_STRING:  // 防御路径：print 对 string 直写不经此
      snprintf(buf, cap, "%.*s", (int)(v->as.str.len < 40 ? v->as.str.len : 40), v->as.str.bytes);
      break;
    case MS_VAL_FUNCTION:
      snprintf(buf, cap, "<func %.*s>", (int)v->as.func->nameLen, v->as.func->name);
      break;
    case MS_VAL_NATIVE:
      snprintf(buf, cap, "<native fn>");
      break;
    case MS_VAL_RANGE_ITER:
      snprintf(buf, cap, "<range-iter>");
      break;
  }
}

MsValue msValueFromConst(const ConstEntry* e, bool* okOut) {
  *okOut = true;
  switch (e->kind) {
    case CONST_NIL:
      return msValueNil();
    case CONST_BOOL:
      return msValueBool(e->as.b);
    case CONST_INT:
      return msValueInt(e->as.i);
    case CONST_FLOAT:
      return msValueFloat(e->as.f);
    case CONST_RUNE:
      return msValueInt((ms_i64)e->as.cp);  // rune 即 int 码点（02 §1）
    case CONST_STRING: {
      MsValue v = {MS_VAL_STRING, {0}};
      v.as.str.bytes = e->as.text.start;
      v.as.str.len = e->as.text.len;
      return v;
    }
    case CONST_PROTO: {
      MsValue v = {MS_VAL_FUNCTION, {0}};
      v.as.func = e->as.proto;
      return v;
    }
    case CONST_BIGINT:
      *okOut = false;  // bigint 执行归 T016（占位错误由 VM 报）
      return msValueNil();
  }
  return msValueNil();
}
```

```c
// 内置桥（T011）：print / range 最小实现（10-builtins §1；完整 Tier0 归 T017）
#include "vm/vm.h"

#include <stdio.h>
#include <string.h>

static void bridgeErr(MsVM* vm, const char* msg) {
  vm->hasError = true;
  snprintf(vm->errMsg, sizeof(vm->errMsg), "%s", msg);
}

static bool needInt(MsVM* vm, const MsValue* v, ms_i64* out) {
  if (v->kind != MS_VAL_INT) {
    bridgeErr(vm, "TypeError: range arguments must be int");
    return false;
  }
  *out = v->as.i;
  return true;
}

// print(...xs)：空格连接 + 换行（Python 语义）；string 直写裸文本（转义解码归 T013）
static MsValue nativePrint(MsVM* vm, int32_t argc, const MsValue* args) {
  for (int32_t i = 0; i < argc; i++) {
    if (i > 0) {
      putc(' ', vm->out);
    }
    if (args[i].kind == MS_VAL_STRING) {
      fwrite(args[i].as.str.bytes, 1, (size_t)args[i].as.str.len, vm->out);
    } else {
      char buf[64];
      msValueToStr(&args[i], buf, sizeof(buf));
      fputs(buf, vm->out);
    }
  }
  putc('\n', vm->out);
  return msValueNil();
}

// range([start,] stop[, step])：惰性 int 迭代器
static MsValue nativeRange(MsVM* vm, int32_t argc, const MsValue* args) {
  ms_i64 start = 0;
  ms_i64 stop = 0;
  ms_i64 step = 1;
  if (argc < 1 || argc > 3) {
    bridgeErr(vm, "ArgumentError: range expects 1-3 arguments");
    return msValueNil();
  }
  if (argc >= 2 ? (!needInt(vm, &args[0], &start) || !needInt(vm, &args[1], &stop))
                : !needInt(vm, &args[0], &stop)) {
    return msValueNil();
  }
  if (argc == 3 && !needInt(vm, &args[2], &step)) {
    return msValueNil();
  }
  if (step == 0) {
    bridgeErr(vm, "ValueError: range step must not be zero");
    return msValueNil();
  }
  MsValue v = {MS_VAL_RANGE_ITER, {0}};
  v.as.range.cur = start;
  v.as.range.stop = stop;
  v.as.range.step = step;
  return v;
}

bool msBuiltinLookup(const char* name, int32_t len, MsValue* out) {
  if (len == 5 && memcmp(name, "print", 5) == 0) {
    out->kind = MS_VAL_NATIVE;
    out->as.native = nativePrint;
    return true;
  }
  if (len == 5 && memcmp(name, "range", 5) == 0) {
    out->kind = MS_VAL_NATIVE;
    out->as.native = nativeRange;
    return true;
  }
  return false;
}
```

```c
// dispatch 采用 computed goto（GCC/Clang）/ switch（MSVC）双展开、单一指令处理体；

#include "vm/vm.h"

#include <stdio.h>
#include <string.h>

#define MS_STACK_MAX (64 * 1024)  // 值栈条目上限（溢出报错；栈深真实限制 T018 评估）
#define MS_SAFEPOINT_BUDGET 1000  // CHECK_SAFEPOINT 回边预算（NOP 递减；抢占 T029）

void msVmInit(MsVM* vm) {
  vm->stack = NULL;
  vm->stackTop = vm->stackCap = 0;
  vm->frames = NULL;
  vm->frameCount = vm->frameCap = 0;
  vm->globals = NULL;
  vm->globalCount = vm->globalCap = 0;
  vm->heap = NULL;
  vm->out = stdout;
  vm->trace = NULL;
  vm->hasError = false;
  vm->errMsg[0] = '\0';
  vm->errLine = -1;
  vm->safepointBudget = MS_SAFEPOINT_BUDGET;
}

void msVmFree(MsVM* vm) {
  free(vm->stack);
  free(vm->frames);
  free(vm->globals);
  msVmInit(vm);
}

static void push(MsVM* vm, MsValue v) {
  if (vm->stackTop >= MS_STACK_MAX) {
    vm->hasError = true;
    snprintf(vm->errMsg, sizeof(vm->errMsg), "StackOverflowError: value stack exceeded %d entries",
             MS_STACK_MAX);
    vm->errLine = -1;
    return;
  }
  MS_ARRAY_PUSH(vm->stack, vm->stackTop, vm->stackCap, v);
}

static MsValue pop(MsVM* vm) {
  MS_ASSERT(vm->stackTop > 0);  // 编译器生成的代码维持栈平衡
  return vm->stack[--vm->stackTop];
}

static MsGlobalVar* findGlobal(MsVM* vm, const char* name, int32_t len) {
  for (int32_t i = vm->globalCount - 1; i >= 0; i--) {  // 后定义覆盖（soft 函数名 05 §1）
    if (vm->globals[i].len == len && memcmp(vm->globals[i].name, name, (size_t)len) == 0) {
      return &vm->globals[i];
    }
  }
  return NULL;
}

static void defGlobal(MsVM* vm, const char* name, int32_t len, MsValue v) {
  MsGlobalVar* hit = findGlobal(vm, name, len);
  if (hit != NULL) {  // 运行时重定义仅 as 绑定兜底等边角；同名重复声明由 binder 拦截
    hit->value = v;
    return;
  }
  MsGlobalVar g = {name, len, v};
  MS_ARRAY_PUSH(vm->globals, vm->globalCount, vm->globalCap, g);
}

// ---- 溢出检查助手（int/int 快路径；溢出为占位错误，bigint 升级归 T016） ----

static bool addOv(ms_i64 a, ms_i64 b, ms_i64* r) {
  if ((b > 0 && a > MS_INT64_MAX - b) || (b < 0 && a < MS_INT64_MIN - b)) {
    return false;
  }
  *r = a + b;
  return true;
}

static bool subOv(ms_i64 a, ms_i64 b, ms_i64* r) {
  if ((b < 0 && a > MS_INT64_MAX + b) || (b > 0 && a < MS_INT64_MIN + b)) {
    return false;
  }
  *r = a - b;
  return true;
}

static ms_u64 absI64(ms_i64 v) { return v < 0 ? (ms_u64)(-(v + 1)) + 1 : (ms_u64)v; }

static bool mulOv(ms_i64 a, ms_i64 b, ms_i64* r) {
  if (a == 0 || b == 0) {
    *r = 0;
    return true;
  }
  ms_u64 ua = absI64(a);
  ms_u64 ub = absI64(b);
  if (ua > (ms_u64)MS_INT64_MAX / ub) {
    return false;
  }
  ms_u64 um = ua * ub;  // |积| ≤ INT64_MAX，正负号均可表示
  *r = (a < 0) != (b < 0) ? -(ms_i64)um : (ms_i64)um;
  return true;
}
```

```c
static bool intPow(ms_i64 base, ms_i64 e, ms_i64* r) {
  if (base >= -1 && base <= 1) {  // |base| ≤ 1：任意 e 结果在 {-1,0,1}
    *r = base == -1 ? (e % 2 == 0 ? 1 : -1) : base;
    return true;
  }
  if (e >= 64) {  // |base| ≥ 2 且 e ≥ 64 必溢出
    return false;
  }
  ms_i64 acc = 1;
  for (ms_i64 i = 0; i < e; i++) {
    if (!mulOv(acc, base, &acc)) {
      return false;
    }
  }
  *r = acc;
  return true;
}

typedef enum BinArith {
  BA_ADD,
  BA_SUB,
  BA_MUL,
  BA_DIV,
  BA_MOD,
  BA_POW,
  BA_BIT_AND,
  BA_BIT_OR,
  BA_BIT_XOR,
  BA_SHL,
  BA_SHR,
} BinArith;

static const char* kBinArithNames[] = {"+", "-", "*", "/", "%", "**", "&", "|", "^", "<<", ">>"};

// 二元算术（21 §3.2 快路径）：int/int 与 float/float；混算升 float；溢出/除零/类型错→false+errMsg
static bool arithBinary(MsVM* vm, BinArith k, MsValue a, MsValue b, MsValue* out) {
  bool aNum = a.kind == MS_VAL_INT || a.kind == MS_VAL_FLOAT;
  bool bNum = b.kind == MS_VAL_INT || b.kind == MS_VAL_FLOAT;
  if (aNum && bNum && a.kind == MS_VAL_INT && b.kind == MS_VAL_INT) {
    ms_i64 r = 0;
    switch (k) {
      case BA_ADD:
        if (!addOv(a.as.i, b.as.i, &r)) goto overflow;
        break;
      case BA_SUB:
        if (!subOv(a.as.i, b.as.i, &r)) goto overflow;
        break;
      case BA_MUL:
        if (!mulOv(a.as.i, b.as.i, &r)) goto overflow;
        break;
      case BA_DIV:
        if (b.as.i == 0) goto divZero;
        if (a.as.i == INT64_MIN && b.as.i == -1) goto overflow;
        r = a.as.i / b.as.i;  // C 截断除法 == Go 语义（-7/2 == -3）
        break;
      case BA_MOD:
        if (b.as.i == 0) goto modZero;
        r = b.as.i == -1 ? 0 : a.as.i % b.as.i;  // INT64_MIN % -1 == 0（避免 UB）
        break;
      case BA_POW:
        if (b.as.i < 0) {  // 负指数转浮点幂（Python 语义）
          *out = msValueFloat(pow((double)a.as.i, (double)b.as.i));
          return true;
        }
        if (!intPow(a.as.i, b.as.i, &r)) goto overflow;
        break;
      case BA_SHL:
        if (b.as.i < 0) goto negShift;
        r = b.as.i >= 64 ? 0 : a.as.i << b.as.i;  // Go 语义：超宽移位为 0
        break;
      case BA_SHR:
        if (b.as.i < 0) goto negShift;
        r = b.as.i >= 64 ? (a.as.i < 0 ? -1 : 0) : a.as.i >> b.as.i;  // 算术右移补符号
        break;
      case BA_BIT_AND:
        r = a.as.i & b.as.i;
        break;
      case BA_BIT_OR:
        r = a.as.i | b.as.i;
        break;
      case BA_BIT_XOR:
        r = a.as.i ^ b.as.i;
        break;
    }
    *out = msValueInt(r);
    return true;
  }
  if (aNum && bNum) {  // 含 float：升 double（02 §3.4 混算表）
    double da = a.kind == MS_VAL_INT ? (double)a.as.i : a.as.f;
    double db = b.kind == MS_VAL_INT ? (double)b.as.i : b.as.f;
    switch (k) {
      case BA_ADD:
        *out = msValueFloat(da + db);
        return true;
      case BA_SUB:
        *out = msValueFloat(da - db);
        return true;
      case BA_MUL:
        *out = msValueFloat(da * db);
        return true;
      case BA_DIV:
        if (db == 0.0) goto divZero;
        *out = msValueFloat(da / db);  // float 真除
        return true;
      case BA_MOD:
        if (db == 0.0) goto modZero;
        *out = msValueFloat(fmod(da, db));  // 符号随被除数 == C fmod
        return true;
      case BA_POW:
        *out = msValueFloat(pow(da, db));
        return true;
      default:  // 位运算拒绝 float（02 §3.1）
        snprintf(vm->errMsg, sizeof(vm->errMsg), "TypeError: bit operation '%s' requires int operands",
                 kBinArithNames[k]);
        return false;
    }
  }
  if (k == BA_ADD && a.kind == MS_VAL_STRING && b.kind == MS_VAL_STRING) {
    snprintf(vm->errMsg, sizeof(vm->errMsg), "RuntimeError: string concatenation executes in T013");
    return false;  // 堆 string 归 T012/T013
  }
  snprintf(vm->errMsg, sizeof(vm->errMsg), "TypeError: unsupported operand types for '%s': '%s' and '%s'",
           kBinArithNames[k], msValueTypeName(&a), msValueTypeName(&b));
  return false;
divZero:
  snprintf(vm->errMsg, sizeof(vm->errMsg), "ArithmeticError: division by zero");
  return false;
modZero:
  snprintf(vm->errMsg, sizeof(vm->errMsg), "ArithmeticError: modulo by zero");
  return false;
overflow:
  snprintf(vm->errMsg, sizeof(vm->errMsg), "OverflowError: int overflow (bigint promotion lands in T016)");
  return false;
negShift:
  snprintf(vm->errMsg, sizeof(vm->errMsg), "ValueError: negative shift count");
  return false;
}
```

```c
        if (it->kind != MS_VAL_RANGE_ITER) {
          RUNTIME_ERROR("TypeError: FOR_ITER over non-iterator '%s'", msValueTypeName(it));

        } else {
          it->as.range.cur = cur + step;
        }
        NEXT();
```

```c
  LoopCtx lc = {NULL, 0, 0, NULL, 0, 0, -1, isIter};

static void endLoop(FuncState* fs) {
  LoopCtx* lc = &fs->loops[fs->loopCount - 1];
  int32_t end = fs->chunk->codeLen;
  for (int32_t i = 0; i < lc->breakCount; i++) {

  free(lc->breaks);
  free(lc->conts);
  fs->loopCount--;
```

```c
static void emitBreak(FuncState* fs, const AstNode* n) {
  if (fs->loopCount == 0) {  // binder 已拦（MSE_BIND_LOOP_ESCAPE）；防御
    compErr(fs, n, 1, "break outside loop");
    return;
  }
  if (currentLoop(fs)->isIter) {
    emitOp(fs, OP_POP, n->line);  // 弹迭代器，保持栈平衡
  }
  int32_t j = emitJump(fs, OP_JMP, n->line);
  LoopCtx* lc = currentLoop(fs);
  MS_ARRAY_PUSH(lc->breaks, lc->breakCount, lc->breakCap, j);
}

static void emitContinue(FuncState* fs, const AstNode* n) {
  if (fs->loopCount == 0) {
    compErr(fs, n, 1, "continue outside loop");
    return;
  }
  int32_t j = emitJump(fs, OP_JMP, n->line);
  LoopCtx* lc = currentLoop(fs);
  MS_ARRAY_PUSH(lc->conts, lc->contCount, lc->contCap, j);
}
```

```c
static void compileIf(FuncState* fs, AstNode* n) {
  compileExpr(fs, n->as.ifStmt.cond);
  int32_t jElse = emitJump(fs, OP_JMP_IF_FALSE, n->line);
  compileStmt(fs, n->as.ifStmt.thenBlock);
  if (n->as.ifStmt.elseNode != NULL) {
    int32_t jEnd = emitJump(fs, OP_JMP, n->line);
    patchJump(fs, jElse);
    compileStmt(fs, n->as.ifStmt.elseNode);  // BLOCK 或 else-if 链（AST_IF）
    patchJump(fs, jEnd);
  } else {
    patchJump(fs, jElse);
  }
}

static void compileFor(FuncState* fs, AstNode* n) {
  if (n->as.forStmt.form == AST_FOR_IN) {
    beginLoop(fs, true);
    compileExpr(fs, n->as.forStmt.iter);
    emitOp(fs, OP_GET_ITER, n->line);
    int32_t lTop = fs->chunk->codeLen;
    currentLoop(fs)->contTarget = lTop;
    int32_t jExit = emitJump(fs, OP_FOR_ITER, n->line);
    AstNode* target = n->as.forStmt.target;
    if (target == NULL) {
      emitOp(fs, OP_POP, n->line);  // 无目标（BAD_TARGET 残留）：丢弃
    } else if (target->kind == AST_IDENT) {
      storeIdent(fs, target);  // binder 已标注（fresh 绑定 04 §4）
    } else {
      compErr(fs, target, 1, "multi-variable iteration lands in T017");
      emitOp(fs, OP_POP, n->line);
    }
    compileStmt(fs, n->as.forStmt.body);
    int32_t jBack = emitJump(fs, OP_JMP, n->line);
    fs->jumps[jBack].target = lTop;
    fs->jumps[jExit].target = fs->chunk->codeLen;
    endLoop(fs);
    return;
  }
  beginLoop(fs, false);
  if (n->as.forStmt.init != NULL) {
    compileStmt(fs, n->as.forStmt.init);
  }
  int32_t lTop = fs->chunk->codeLen;
  if (n->as.forStmt.form != AST_FOR_TRI) {
    currentLoop(fs)->contTarget = lTop;  // COND/INF：continue 回条件/体首
  }
  int32_t jExit = -1;
  if (n->as.forStmt.cond != NULL) {
    compileExpr(fs, n->as.forStmt.cond);
    jExit = emitJump(fs, OP_JMP_IF_FALSE, n->line);
  }
  compileStmt(fs, n->as.forStmt.body);
  if (n->as.forStmt.form == AST_FOR_TRI) {
    currentLoop(fs)->contTarget = fs->chunk->codeLen;  // continue 先执行 post
  }
  if (n->as.forStmt.post != NULL) {
    compileStmt(fs, n->as.forStmt.post);
  }
  int32_t jBack = emitJump(fs, OP_JMP, n->line);
  fs->jumps[jBack].target = lTop;
  if (jExit >= 0) {
    fs->jumps[jExit].target = fs->chunk->codeLen;
  }
  endLoop(fs);
}

static void compileWhile(FuncState* fs, AstNode* n) {
  beginLoop(fs, false);
  int32_t lTop = fs->chunk->codeLen;
  currentLoop(fs)->contTarget = lTop;
  compileExpr(fs, n->as.whileStmt.cond);
  int32_t jExit = emitJump(fs, OP_JMP_IF_FALSE, n->line);
  compileStmt(fs, n->as.whileStmt.body);
  int32_t jBack = emitJump(fs, OP_JMP, n->line);
  fs->jumps[jBack].target = lTop;
  fs->jumps[jExit].target = fs->chunk->codeLen;
  endLoop(fs);
}

// 类型式 as 绑定落盘（判别值已在栈顶；binder 标注见 binder.c AST_SWITCH）
static void storeCaseBinding(FuncState* fs, const AstNode* c) {
  if (c->bindKind == AST_BIND_LOCAL) {
    emitOp(fs, OP_STORE_LOCAL, c->line);
    emitByte(fs, (ms_u8)c->bindSlot);
  } else {
    int32_t k = nameConst(fs, c->as.switchCase.bindName, c->as.switchCase.bindLen);
    emitConstOp(fs, OP_DEF_GLOBAL, k, c->line);
    emitConstOp(fs, OP_STORE_GLOBAL, k, c->line);
  }
}

// switch 值/类型式统一比较链（04 §5；SWITCH_TABLE 跳转表优化后置）
// 判别值驻栈，逐 case 逐值 DUP+测试+假跳；命中落体，default 兜底，无 fallthrough
static void compileSwitch(FuncState* fs, AstNode* n) {
  compileExpr(fs, n->as.switchStmt.subject);
  int32_t* endJumps = NULL;
  int32_t endCount = 0, endCap = 0;
  AstNode* defaultCase = NULL;
  for (int32_t i = 0; i < n->as.switchStmt.count; i++) {
    AstNode* c = n->as.switchStmt.cases[i];
    if (c->as.switchCase.isDefault) {
      defaultCase = c;
      continue;
    }
    int32_t* tests = NULL;
    int32_t testCount = 0, testCap = 0;
    for (int32_t v = 0; v < c->as.switchCase.valueCount; v++) {
      AstNode* vn = c->as.switchCase.values[v];
      emitOp(fs, OP_DUP, vn->line);
      if (n->as.switchStmt.isType) {
        if (vn->kind != AST_IDENT) {
          compErr(fs, vn, 1, "type case expects a type name");
          emitOp(fs, OP_POP, vn->line);  // 弹 DUP 保持平衡
        } else {
          int32_t k = nameConst(fs, vn->as.ident.name, vn->as.ident.nameLen);
          emitConstOp(fs, OP_CHECK_TYPE, k, vn->line);
        }
      } else {
        compileExpr(fs, vn);  // case 值任意表达式，== 语义（04 §5.1）
        emitOp(fs, OP_COMPARE_EQ, vn->line);
      }
      int32_t jt = emitJump(fs, OP_JMP_IF_FALSE, vn->line);
      MS_ARRAY_PUSH(tests, testCount, testCap, jt);
    }
    if (c->as.switchCase.bindName != NULL) {  // 命中：判别值出栈入绑定
      storeCaseBinding(fs, c);
    } else {
      emitOp(fs, OP_POP, c->line);
    }
    compileStmt(fs, c->as.switchCase.body);  // 可为 NULL（解析残留；诊断已发）
    int32_t je = emitJump(fs, OP_JMP, c->line);
    MS_ARRAY_PUSH(endJumps, endCount, endCap, je);
    for (int32_t t = 0; t < testCount; t++) {
      patchJump(fs, tests[t]);  // 假跳落至下一测试/兜底
    }
    free(tests);
  }
  if (defaultCase != NULL) {  // 全测试未命中：default 体（任意位置合法）
    if (defaultCase->as.switchCase.bindName != NULL) {
      storeCaseBinding(fs, defaultCase);
    } else {
      emitOp(fs, OP_POP, defaultCase->line);
    }
    compileStmt(fs, defaultCase->as.switchCase.body);
  } else {
    emitOp(fs, OP_POP, n->line);  // 仅弹判别值
  }
  for (int32_t e = 0; e < endCount; e++) {
    patchJump(fs, endJumps[e]);
  }
  free(endJumps);
}
```
