# T038 — ms fmt 格式化器

- 阶段: P11 工具链（roadmap 期 11）
- 依赖: T009
- 规模: L
- 状态: 未开始
- 设计文档: `docs/language/11-style-ms.md` §2 §3 §6、`27-toolchain.md` §3

## 1. 目标与范围

实现 `ms fmt`：基于 AST 的格式化输出（唯一风格），执行 11 §2 全部格式规则与 §6 机械化禁止项修复（分号剔除、Tab→4 空格、行尾空白清除、`and/or/not`→`&&/||/!` 归一、import 分组排序）；`--check`/`--diff` 模式；幂等性 fmt(fmt(x)) == fmt(x)。

不做：超出 11 §2 的风格主观化重排（不合并/拆分短行、不重排参数）、行宽 100 的强制硬换行（尽力断行，无法安全断行保留长行 + stderr 告警）。

## 2. 实现要点

- 输入→scanner→parser→AST→printer（复用前端，20 §1 前端复用声明）；注释保留（token 流侧挂 + 粘贴回输出，含 `///` 文档注释相对声明位置）。
- 规则清单（11 §2）：
  - 缩进 4 空格；K&R 左大括号不换行；一行一语句（ASI 产物分号在输出中消隐）
  - 二元运算符两侧空格；逗号后空格；`(`/`[` 内侧无填充
  - 关键字后一空格；函数名后不加
  - 空行：函数间 1、类内方法间 1、文件末尾恰 1 换行；连续 2+ 空行压 1
  - import 组间 1 空行、组内路径字母序（标准库→第三方→本地相对）
  - 行宽 100：超限在二元运算符/逗号/括号处尽力断行（断行缩进 +4 或对齐括号），硬限 120 超限保留 + 告警
- 运算符归一（01 §2）：`and or not` → `&& || !`。
- 禁止项修复（11 §6）：源码分号（非 ASI 语义处）报错并剔除；Tab 缩进替换；行尾空白清除；`import *` 在脚本文件报错（REPL 除外——fmt 对 stdin 输入不查）。
- 幂等（27 §3）：对自身输出再 fmt 无 diff——以"print 深度遍历不依赖原始空白"保证；无法安全断行的长行（长字符串字面量等）保留并 stderr 告警。
- 模式：默认写回、`--check`（非零退出 3，27 §10）、`--diff`（统一 diff 输出）；支持文件与目录递归。
- 失败安全：语法错误文件跳过 + 报错（不写回），不阻断其余文件。

## 6. 风险与备注

- 注释粘贴是 AST printer 最繁琐部分：策略 = 语句级前后注释挂靠（按行号区间归属），行内尾注释（隔 2 空格）随语句输出。
- 本仓库自身 ms 样例/文档中的 .ms 代码块也应符合 fmt 风格（doc-sync 范畴，本任务只在 CI 加 `ms fmt --check examples/ tests/fixtures/`）。
