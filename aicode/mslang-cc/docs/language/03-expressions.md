# 03 表达式

优先级从低到高（同级左结合，赋值除外）：

| 级 | 运算符 | 说明 |
|----|--------|------|
| 1 | `?:` | 三元，右结合 |
| 2 | `||` / `or` | 短路 |
| 3 | `&&` / `and` | 短路 |
| 4 | `==` `!=` `<` `<=` `>` `>=` `is` `in` | 比较，不可链式（`a < b < c` 非法） |
| 5 | `\|` | 按位或 |
| 6 | `^` | 按位异或 |
| 7 | `&` | 按位与 |
| 8 | `<<` `>>` | 移位 |
| 9 | `+` `-` | 加减 |
| 10 | `*` `/` `%` | 乘除模 |
| 11 | `**` | 乘方，右结合 |
| 12 | 一元 `!` `-` `~` | |
| 13 | `<-ch`（前缀接收）、`await`、`go` | |
| 14 | 后缀：调用 `( )`、成员 `. `、索引 `[ ]`、切片 `[a:b:c]` | 左结合链 |

## 1. 字面量与构造表达式

- 各类型字面量见 `02-types.md`。
- 函数表达式：`func(a, b) { return a + b }`（匿名函数是一等值）。
- 生成器表达式（惰性）：`(x * x for x in xs if x > 0)`，只能作调用实参或赋值右值。

## 2. 推导式

```ms
[x * x for x in xs if x % 2 == 0]          // list 推导
{k: len(v) for k, v in m.items()}          // map 推导
{x % 3 for x in xs}                        // set 推导
```

- 语法：`[expr for name in iterable (if cond)*]`；支持多 `for` 嵌套与多 `if`（合取）。
- 第一个 `for` 前的作用域为外层；迭代变量在推导式作用域内新建，不泄漏（Python 3 语义）。

## 3. 成员访问 / 索引 / 切片

- `obj.field`、`obj.method(args)`、`Class.staticMember`。
- `xs[i]`、`m[k]`、`f.__name__`；负索引仅 string/list/tuple。
- 切片对象不独立暴露，仅 `x[a:b:c]` 语法（对 string/list/tuple 有效；步进可负，a/b 可省略）。
- 元素读写协议：`__getitem__ / __setitem__`（见 `06-classes.md`）。

## 4. 调用

- 位置实参 + 默认实参 + `*` 展开序列：`f(1, *xs)`。
- 实参求值顺序：从左到右。
- 调用协议：`__call__`；method 调用走 INVOKE 内联缓存（实现见 `21-bytecode.md`）。

## 5. 逻辑与比较

- `&& / ||` 短路并**返回操作数本身**（非 bool 化）：`nil || "d" == "d"`。
- `!` 返回 bool。
- `in`：右侧需支持 `__contains__`（string/list/tuple/set/map(键)/自定义）。
- `is`：同一性，不可重载。

## 6. 运算符重载（dunder 映射）

| 运算符 | dunder | | 运算符 | dunder |
|--------|--------|-|--------|--------|
| `+` | `__add__` | | `==` | `__eq__` |
| `-` | `__sub__` | | `<` | `__lt__` |
| `*` | `__mul__` | | `<=` | `__le__` |
| `/` | `__truediv__` | | `>` | `__gt__` |
| `%` | `__mod__` | | `>=` | `__ge__` |
| `**` | `__pow__` | | `in` | `__contains__` |
| `& \| ^ << >>` | `__and__ __or__ __xor__ __shl__ __shr__` | | 一元 `-` | `__neg__` |
| 一元 `~` | `__invert__` | | 一元 `!` | 不可重载 |

- 无反射运算符（`__radd__` 等）：左操作数优先，左无 dunder 且右同类不匹配直接 TypeError。
- `!=` 自动由 `__eq__` 取反；`>=/>/<=` 在仅有 `__lt__/__eq__` 时自动推导。
- 数值类型操作数与实例混算：数值侧永不调用实例 dunder，直接 TypeError（规则简单，避免反射复杂度）。

## 7. 三元

`cond ? a : b`；右结合；`a/b` 惰性求值。

## 8. 并发表达式

- `go f(x)` / `go func() { ... }()`：启动 goroutine，返回其 **Future**（await 即 join；`runtime.cancel(fut)` 取消；弃置不等待即发射后不管）。
- `await fut`：只能在 async 函数或模块顶层使用；见 `08-concurrency.md`。
- `<-ch`：channel 接收表达式；`ch <- v` 是**语句**（见 `04-statements.md`）。

## 9. 插值字符串

- `"${expr}"`：expr 为任意表达式；求值后以 `str(expr)` 规则转字符串（instance 走 `__str__`，否则 `__repr__`）。
- 嵌套引号允许：`"${"inner"}"`。

## 10. 分组与换行

- `(expr)` 分组；括号内换行不触发 ASI（长表达式换行风格见 `11-style-ms.md`）。
- 函数调用 `f(\n` 换行合法（括号未闭合）。
